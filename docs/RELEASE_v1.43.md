# v1.43 — каналы в списке кампаний

Username в карточках кампаний стал прямой ссылкой на Telegram. После временного сбоя аватарки повторно запрашиваются при обновлении списка вместо сохранения пустого результата на весь сеанс. Увеличено время ожидания ответа Telegram для фотографий с 2 до 8 секунд.

Главная: баланс убран; красная кнопка «Подключить прокси» под созданием кампании использует текущую публичную ссылку из того же файла, что бот. Если ссылка не настроена, кнопка показывает понятное сообщение. Приглашение друзей перенесено в конец страницы.
