# Реальный интерфейс MTProxy Pushok

Снимки создаются Chromium из `api/web/index.html`, `help.html`, `styles.css` и `app.js`.
Это существующий интерфейс, а не нарисованный макет. Ответы API синтетические:
настоящие аккаунты, платежи, секреты и прокси в подготовке изображений не участвуют.
Данные примера, включая цену Stars, не являются настройками работающего сервера.

## Как получить снимки

В GitHub Actions откройте запуск **API and PostgreSQL checks** для нужного коммита.
После успешного задания `cabinet-preview` скачайте архив `pushok-cabinet-previews`.
Изображения хранятся 14 дней; доступ определяется настройками GitHub и репозитория.

Для локального воспроизведения:

```bash
python -m pip install playwright==1.56.0
python -m playwright install --with-deps chromium
python scripts/render_cabinet_previews.py --out .build/ui-preview
```

Если Chromium уже установлен, его можно указать через
`--browser-executable /usr/bin/chromium`.

Сценарий поднимает временный HTTP-сервер только на `127.0.0.1`, подменяет ответы
API внутри браузера и проверяет ширину мобильного кабинета и справки на 390 px.
Ожидание данных настроек завершается до снимка. Скриншоты не подтверждают работу
Telegram, эквайринга, спонсорского канала или установки на VPS.
