# MTProxy Pushok v2.03

Исправлено обновление кабинета с включёнными уведомлениями Flow. Служба уведомлений приостанавливается вместе с остальными службами записи на время резервного копирования и возвращается после него.

Если v1.127 остановилась на этапе «резервная копия» при работающем flow-push, из каталога установки запустите обновлятор стабильного выпуска. Он берёт штатную блокировку, создаёт и проверяет копию работающей установки, затем обновляет исходники, выполняет миграции и проверяет доступность кабинета.

```bash
cd /opt/mtproxy-pushok && git fetch --no-tags origin refs/heads/release/stable && git show FETCH_HEAD:scripts/recover_flow_push_update.sh | bash
```
