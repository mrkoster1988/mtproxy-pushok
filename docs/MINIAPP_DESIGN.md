# Перенос дизайна Mini App

Изменения продолжают кабинет `/miniapp` и внешний веб-кабинет в ветке `design/reference-cabinet`, PR #61. Нового приложения, миграций БД и изменений платёжных разрешений нет.

| Экран | Источник и действие |
| --- | --- |
| Главная | Собственные кампании и их реальные статусы |
| Мои каналы | Существующий CRUD; выбранный канал переносится в форму |
| Новая кампания | Существующая атомарная заявка и защита от повторов |
| Календарь | Доступность API; дата — пожелание, не бронь |
| Кампании | Карточки, поиск и фильтр статуса |
| Карточка кампании | Модерация, оплата, размещение; исправление и история |
| Мои оплаты | Список одобренных заявок и подтверждённые статусы |
| Оплата Stars | Сумма XTR и invoice от API; результат подтверждает сервер |
| Профиль | Разделы по роли, помощь, архив и выход |
| Отчёты | Подтверждённая история; CSV на внешнем сайте |
| Спонсоры | Активные и оплаченные запланированные кампании, управление по роли |

В макетах кошелёк и бонусы показывали направление дальнейшей разработки. Соответствующего API пока нет: вместо вымышленного баланса отображаются оплаты заявок. Цена в рублях — сохранённая стоимость заявки, цена XTR задаётся отдельно. СБП остаётся во внешнем кабинете.

## Проверка перед выпуском

- `python -m unittest discover -s tests`: локальные проверки; интеграционные требуют PostgreSQL.
- CI `cabinet-preview`: реальный API и PostgreSQL, роли, создание/исправление/модерация, тестовые Stars и СБП, отчёты, архив, мобильная компоновка.
- Локальный просмотр с синтетическими ответами проверяет только внешний вид и переходы; он не подтверждает обработку настоящих оплат.
- Перед переключением установленного VPS проверить вход в Telegram, safe area, клавиатуру, открытие тестового invoice и получение серверного receipt на своей конфигурации.

Рабочие данные и платёжные настройки при обновлении дизайна не заменяются. Stable-релиз публикуется отдельно после приёмки.
