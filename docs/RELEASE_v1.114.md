# v1.114 — Квадратный блок подключения

Квадратный блок подключения занимает свободное место на главной. Приглашение и лидеры оформлены карточками одинакового размера.

Кнопка «Подключить» круглая, с пульсирующей красной обводкой. Пушок подходит к ней и показывает лапой.

При включённом системном уменьшении движения Пушок показывает на кнопку в статичной позе.
