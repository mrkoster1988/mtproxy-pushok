# v1.31 — баланс, подарочные ссылки и компактная сверка

Ошибка поиска Telegram ID теперь отображается внутри управления балансами. Форма, навигация и кнопка «К моему балансу» остаются доступными после ошибки, обновления и возврата на страницу. Можно искать зарегистрированного пользователя по ID, @username или имени. Неизвестный аккаунт не создаётся автоматически: он появляется после входа в кабинет. Для подарка до первого входа используйте персональный подарочный код.

«Поделиться» у подарочных кодов, предложений и купонов создаёт короткое сообщение с `https://t.me/<bot>?startapp=…`. Для такой ссылки нужно включить Main Mini App этого бота в @BotFather и указать URL `https://<домен>/miniapp`. Получатель проходит обычный проверенный вход. Подарок начисляется один раз; повторный переход показывает уже зачисленный подарок. Персональный код и купон не становятся общедоступными от пересылки.

Ссылка на предложение выбирает подходящий тариф и рассчитывает скидку в форме. Заявка и счёт не создаются до действий пользователя. Лимит расходуется только при отправке заявки. Процентная скидка теперь действует и в Mini App: она отдельно уменьшает заданные цены ₽ и Stars, с округлением Stars вверх. Например, 151 Stars со скидкой 40% → 91 Stars. Самая выгодная скидка применяется одна; скидки не складываются. Бонусные рубли остаются отдельным балансом для рублёвых заказов, не конвертируются в Stars. Уже созданные заявки и счета не пересчитываются.

В последних пополнениях показаны имя, один никнейм, ID, сумма и статус; полный ID платежа находится в подробностях. Для пользователя без фото отображается компактная аватарка с инициалами.

Ссылку `tg://stars` внутри WebView некоторые клиенты Telegram игнорируют. В Mini App кнопка открывает бота с параметром `stars`; бот выдаёт нативную ссылку «Открыть мои Stars», которую нужно нажать в чате. Прямой вход в личный баланс через Web App API не заявляется. Ручной путь: Telegram → Настройки → Мои звёзды. Документация: https://core.telegram.org/api/links#my-stars-links.

Пустой узел без кампании теперь находится в ожидании, а не создаёт инцидент отсутствующего тега. Будущая кампания ждёт даты старта. Если наступил период оплаченного и одобренного размещения, а привязки нет, ошибка остаётся: администратор должен открыть «Узлы и спонсорство», выбрать канал и узел и сохранить тег из @MTProxybot. Агент применит подготовленный тег автоматически. Обновление не создаёт и не угадывает теги Telegram.

Миграция БД не требуется. Проверки включают PostgreSQL, повторные запросы, доступ к персональным предложениям, цену счёта Stars, ошибочный поиск с возвратом и открытие ссылок через подписанный initData с настоящим SDK Telegram и тестовым нативным мостом. Проверка клиента Telegram на устройстве и установка на VPS выполняются отдельно.

Установка: **Профиль → Версия и обновления → Установить v1.31** после публикации стабильной версии.
