# MTProxy Pushok v1.03

## Создать тариф

Откройте **Профиль → Настройки → Тарифы → + Новый тариф**.

1. Укажите название и длительность. Единица — часы или дни, общая длительность от 1 часа до 365 дней.
2. Выберите аудиторию: все рекламодатели или только администратор. Административные тарифы всегда бесплатные; аудитория существующего тарифа не переключается.
3. Для платного тарифа укажите цену от 1 ₽. Цену Stars задайте отдельно; пустое поле или 0 отключают Stars для этого тарифа.
4. Для нулевой стоимости включите **Бесплатный тариф**: цена станет 0 ₽, цена Stars очистится. Также можно вручную указать 0 ₽ и пустое поле/0 Stars.
5. Проверьте предпросмотр. Включите **Доступен для новых заявок**, если тариф должен сразу появиться в выборе.
6. Нажмите **Создать**. Тариф появится в списке для последующего редактирования.

Бесплатная заявка проходит обычную модерацию. После одобрения она готова к назначению без внешней оплаты, но не становится активной автоматически: расписание и подтверждение фактического показа сохраняются.

Платёжные способы включаются отдельно во вкладке «Платежи». Создание тарифа само по себе не включает Stars или СБП. Изменения цены и длительности действуют для новых заявок; старые сохраняют снимки условий.

## Надёжность

Создание и запись аудита выполняются в одной транзакции. Повтор одного запроса возвращает тот же тариф. Запрос с уже использованным UUID и другими условиями отклоняется; удалённый тариф таким повтором не восстанавливается.

Черновик сохраняется при переключении вкладок настроек до выхода или перезагрузки страницы. «Отмена» возвращает к выбранному ранее тарифу. Удаление использует существующий раздел «Удалённые».

Миграций БД и изменений параметров MTProxy в выпуске нет. Проверки включают роли API, нулевые/некорректные цены, повторные запросы, бесплатную заявку на PostgreSQL, неизменность прежней цены и мобильный конструктор 320/390 px.
