# v1.54 — Подтверждение номера без зависания

В v1.53 контакт появлялся в чате Telegram, но API отклонял запрос бота: обработчики подтверждения и поздравлений ожидали `X-Bot-Secret`, а бот отправлял `X-Pushok-Bot-Secret`. Исправлены все четыре маршрута. Проверка служебного секрета и среды Telegram сохраняется.

В Mini App появилась кнопка «Отменить ожидание». Сетевой запрос прерывается через 8 секунд, ожидание ответа бота после отправки контакта — через 12 секунд. При задержке остаются проверка статуса и ссылка «Подтвердить через бота». Получение доступной даты рождения Telegram ограничено 3 секундами; отсутствие даты не мешает сохранить контакт.

## Проверки

Регрессионный тест запускает polling бота с собственным контактом, использует настоящий конструктор HTTP-запроса и передаёт его в API с отдельной PostgreSQL. Он проверяет сохранение номера, годовое начисление, получение и подтверждение доставки поздравления. Подменяется только соединение с Telegram и локальным API, а не заголовки или логика обработки.

Chromium проверяет отмену native-окна, отсутствие галочки по одному клиентскому callback, отмену ожидания, задержку бота, зависшее соединение, повторную попытку и подтверждение через обработчик бота. Настоящие контакты и поздравления не отправляются.

## После установки

Установите обновление через «Профиль → Версия и обновления», закройте Mini App и откройте снова. Сначала нажмите «Проверить статус». Если номер ещё не подтверждён, снова нажмите «Подтвердить номер» и разрешите передачу контакта: старый запрос мог истечь. Сумма бонуса остаётся в настройках администратора.
