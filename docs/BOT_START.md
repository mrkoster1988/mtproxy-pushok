# Минимальный Telegram-бот MTProxy Pushok

**Стадия:** исходный код и тесты, не развёрнут. Команды зарегистрированы пользователем в BotFather: /start, /advertise, /campaigns, /tariffs, /channels, /help.

## Запуск локально (только для тестирования)

Нужен Python 3.12+ и **токен из BotFather**, который хранится вне Git. Запустите только один экземпляр:

```bash
export TELEGRAM_BOT_TOKEN='ваш_секретный_токен'
python -m bot.main
```

Бот использует long polling (`getUpdates`), не может работать одновременно с активным webhook; скрипт не удаляет webhook автоматически и не меняет другие Telegram-настройки. Для фоновой эксплуатации потребуется отдельный процесс-супервизор и безопасная передача секретов. Не запускайте его параллельно с другим ботом на том же токене.

## Функции этой итерации

- `/start`: интерактивное меню;
- `/tariffs`: базовый тариф 1 день — 300 ₽;
- `/channels`: ссылка https://t.me/pushok_proxy;
- `/advertise`: как написать каналу;
- `/campaigns`: честное сообщение, что личные кампании ещё не интегрированы;
- `/help`: поддержка.

Кнопки работают через `callback_query`, уведомление о нажатии подтверждается `answerCallbackQuery`. Покупки, создание заявок, оплата, доступ к базе, MTProxy и статистика здесь **не реализованы**.

## Проверка

```bash
python -m unittest tests.test_bot -v
```

Ни одна команда проверки не требует токена или сети. Не публиковать бот как рабочую платёжную систему до интеграционных испытаний.
