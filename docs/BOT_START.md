# Telegram-бот MTProxy Pushok — v0.014 (код, не развёрнут)

Бот: https://t.me/mtproxy_pushok_bot · канал: https://t.me/pushok_proxy

## Возможности текущего этапа

- Команды `/start`, `/advertise`, `/campaigns`, `/tariffs`, `/channels`, `/help` и интерактивные кнопки.
- Понятное сообщение о тарифе «1 день — 300 ₽» и о том, что коммерческие размещения пока не запущены.
- Проверка `getMe` при старте: предоставленный токен должен принадлежать **@mtproxy_pushok_bot**.
- Проверка `getWebhookInfo`: при активном webhook бот **отказывается** запускать polling, ничего не удаляет в настройках Telegram.
- Long polling с обработкой `callback_query` и осторожным подтверждением update только после обработки.

**Не реализовано:** получение кампаний из БД, создание заказов в боте, оплата Stars, управление MTProxy и статистика прокси. Это следующий этап. Текущий сервис не означает, что бот уже отвечает пользователям.

## Безопасная установка на тестовом сервере

Требуется собственный Docker/Compose и доступ к приватному репозиторию. В `.env` должен находиться реальный `TELEGRAM_BOT_TOKEN`. Никогда не отправляйте токен в чат, коммиты, публичные issue или скриншоты. Если токен ранее был раскрыт, выпустите новый через BotFather.

Проверки конфигурации **до** запуска:

```bash
docker compose --profile bot config --quiet
python3 -m unittest tests.test_bot -v
```

Запустить только бота (не развёртывает API/БД/прокси):

```bash
docker compose --profile bot up -d --build bot
docker compose --profile bot ps bot
docker compose --profile bot logs --tail=50 bot
```

Остановить:

```bash
docker compose --profile bot stop bot
```

Сервис изолирован от внутренней сети БД; ему разрешён только исходящий доступ для запросов к Telegram API. Он не публикует TCP-порты. Бот работает с отключённой записью в корневую файловую систему и без привилегий root.

Не запускайте два обработчика сообщений на одном токене. Если webhook используется другим приложением, сначала выясните его назначение и решите конфликт вручную: наш код **не вызывает** `deleteWebhook`.

## Приёмка

1. `python3 -m unittest tests.test_bot -v` завершается без ошибок.
2. `docker compose --profile bot config --quiet` завершается без ошибок.
3. После добровольного старта в Telegram бот отвечает на `/start` и кнопки без дублирования сообщений.
4. Условия незапущенных услуг показаны честно, без запроса денег.
5. Остановка контейнера не останавливает API, базу данных или магазин Pushok VPN.

В этой итерации этапы 3–5 **не подтверждены на реальном сервере**. До боевой готовности не помечать как выполненные.

**Важно:** `setup.sh` пока не запускает бот автоматически. Это намеренно: установка одной командой будет расширена после безопасного тестового запуска.
