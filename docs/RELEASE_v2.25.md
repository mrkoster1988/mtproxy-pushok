# Прямые регистрации

Новые пользователи, пришедшие без реферальной ссылки, появляются в приглашённых основного разработчика. При входе по действующей ссылке приглашение получает её владелец. Уже зарегистрированные пользователи без пригласившего тоже зачислены разработчику. Прошлые заказы и выплаты сохраняются. На Android кнопка «Скачать Pushok Flow» передаёт APK в браузер для установки.
