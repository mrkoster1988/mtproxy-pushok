# Компактная карточка VPN

В карточке VPN последний IP подключения, страна и IP туннеля размещены в одной строке слева направо. Уменьшены интервалы между сведениями о подписке.

В профиле появился раздел «Настройки → Бот Pushok ИИ». Владелец и разработчик могут подключить @server_pushok_bot или заменить его токен.
