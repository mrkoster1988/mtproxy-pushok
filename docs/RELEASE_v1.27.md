# v1.27 — посетители, предложения и возвраты

- **Профиль → Посетители** (администратор): имя, username, Telegram ID, первый вход, последняя активность, число открытий и поиск. Учитываются авторизованные открытия кабинета; исторические данные восстановлены только из сохранившихся сессий.
- Меню бота: размещение рекламы зелёное, помощь голубая. Новое меню появляется после `/start`; ранее отправленные сообщения не переписываются.
- У «Модерации» красный счётчик неархивных заявок со статусами ожидания, исправлений и отказа. Доступен администраторам и операторам.
- Значок «Поделиться» встроен в кнопку и не зависит от старого кэша SVG. Промокод предлагается автоматически и редактируется перед созданием.
- **Бонусы и приглашения**: отправка промокодов, скидок и подарочных размещений через выбор получателя Telegram. Личный купон передаётся первому принявшему одноразовую ссылку. До принятия он остаётся владельцу; использованный купон передать нельзя. Остаются исходные срок, лимит и ограничения.
- **Кампании → карточка → Возврат оплаты** (администратор): полный или частичный возврат СБП и рублёвого баланса, полный возврат Telegram Stars. Сумма, причина, подтверждение и история. Ручная оплата: только запись уже выполненного вне кабинета возврата.

Возвращается исходный способ оплаты. Бонусные рубли не превращаются в денежные. Для СБП минимум 1 ₽; остаток — 0 либо от 1 ₽. Stars API не поддерживает частичную сумму. Действующее размещение нужно сначала остановить; будущее отменяется при запросе возврата. Связанная реферальная награда отзывается и при частичном возврате.

Запрос сохраняется до обращения к провайдеру. Повторная отправка использует тот же ключ; одновременно разрешён один незавершённый возврат кампании. Неопределённый результат требует сверки, а не новой выплаты. При потерянном ответе ЮKassa можно указать ID возврата: сервер проверяет платёж, сумму, магазин и результат. После 23 часов новый POST по старому ключу запрещён. Реальные платежи и сообщения тестами не отправляются.

Установка: **Профиль → Версия и обновления**. После установки заново открыть кабинет и отправить `/start` боту для нового меню.
