# CI/CD MTProxy Pushok — временный порядок при блокировке GitLab

Дата решения: 2026-11-07.

## Подтверждённая внешняя блокировка

GitLab.com отклоняет создание pipeline для `main`:

```
Identity verification is required in order to run CI jobs
```

Зафиксирован отказ API при создании нового pipeline (HTTP 400), ранее создававшиеся pipeline сразу получали статус `failed`, список jobs был пуст. Это **не свидетельствует о падении Python-тестов**.

Документация GitLab: https://docs.gitlab.com/ci/debugging/#error-identity-verification-is-required-in-order-to-run-ci-jobs

## Решение на время блокировки

1. **GitHub — основной CI.** Файл `.github/workflows/check.yml`: Python 3.12, PostgreSQL 16, `python -m unittest discover -s tests -v`. Оценивать результат **каждого конкретного коммита**, а не старого успешного запуска.
2. **GitLab — приватный зеркальный репозиторий.** Каждое изменение отправлять и туда, по возможности сверять содержимое файлов. Отсутствие успешно запущенного GitLab CI отражать в отчёте честно.
3. Не отключать проверки в GitHub и не объявлять релиз готовым, если последний GitHub Actions workflow не прошёл.
4. Не выполнять deployment на сервер и не открывать сайт публично без отдельного решения владельца.
5. Когда GitLab разрешит запуск: восстановить параллельный CI, убедиться в успешных тестах и убрать временную оговорку.

## Официальные варианты GitLab

- Завершить верификацию аккаунта.
- Использовать собственный project/group runner (потребуется безопасная установка и обслуживание).
- Рассмотреть платный тариф или дополнительные вычислительные минуты, если это оправдано.
- Если проверка не работает, обратиться в поддержку GitLab с текстом ошибки без пересылки токенов и платёжных данных.

Не добавлять неизвестные токены или SSH-ключи в коммиты, обращения или переписку.

## Приёмка v0.012 с временной блокировкой

Релиз допускается после **успешного GitHub Actions на коммите релиза**, прохождения необходимых локальных/интеграционных тестов, проверки версий, документации и синхронизации исходников в оба приватных репозитория. GitLab CI отмечается отдельно как **внешне заблокированный**, а не как успешный.
