# v1.35 — подарочные ссылки и уведомления

У сообщения об ошибке исправлена мобильная вёрстка: текст и закрытие находятся
в первой строке сетки, действие — ниже. Кнопка повтора больше не наследует
крупный размер крестика. Ошибку ссылки можно закрыть или уйти в другой раздел;
она не исчезает через пять секунд во время чтения.

API различает неизвестный подарочный код, другого получателя, отключение,
удаление, истёкший срок и исчерпанный лимит. В случае другого получателя
приложение показывает никнейм и ID **текущего** аккаунта. Данные назначенного
получателя ему не раскрываются. Проверка привязки остаётся по Telegram ID.
У сообщения есть окончание кода, чтобы сравнить его с карточкой администратора.

«Повторить» показывается при проблеме связи, ответе 5xx или ограничении 429.
Повтор после потерянного ответа о зачислении возвращает прежний результат и
не создаёт вторую проводку. Срок, лимит, активность и ограничения получателя
по-прежнему проверяются сервером.

Значки «Изменить» и «Удалить» получили явные атрибуты SVG. Версия адреса
спрайта обновлена, поэтому Mini App не использует старый файл без новых значков.

Проверки: 817 unittest (10 пропусков); реальные API/PostgreSQL и подписанный
вход Mini App в Chromium. Покрыты неправильный аккаунт, смена аккаунта
с сохранённой сессией в том же WebView, повторный вход, потерянный ответ после
начисления и мобильные ширины 320/390 px. Миграции не требуются.

Обновление: **Профиль → Версия и обновления → Установить v1.35**.
По одним скриншотам невозможно подтвердить причину отказа конкретного кода
на VPS; этот релиз устраняет ошибки отображения и показывает точную причину
последующего отказа. Публикация не означает установку на сервер.
