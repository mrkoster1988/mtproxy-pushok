# v1.95 — приглашения, бонусы и пересмотр модерации

Администратор может назначать приглашённых из профиля и настроить разовый бонус за регистрацию для новых и существующих пользователей.

Рейтинг и награды рассчитываются за месяц и год.

Отказ агента можно пересмотреть вручную. Описание канала и дата проверки видны в карточке. Исправлено управление списками выбора.

Для назначения откройте профиль пригласившего, раскройте «Приглашено» и выберите пользователя. Предыдущие выплаты сохраняются. Сумма приветственного бонуса задаётся в настройках реферальной программы в рублях, 0 отключает начисление.
