# v1.76 — Автопривязка и ручное сохранение тега

Зарегистрированный прокси мог отображаться как «Прокси не найден в аккаунте владельца». Фильтр кнопок ожидал `KeyboardButtonCallback`, тогда как закреплённая библиотека Telethon 1.45.0 возвращает `KeyboardInlineButton` с вложенным `InlineButtonTypeCallback`. В результате агент пропускал подходящую кнопку списка ещё до открытия карточки.

Агент распознаёт оба формата. Для новых кнопок проверяется вложенный тип действия: разрешены callback без запроса пароля и обычный текст. Ссылки, авторизация, запрос контакта или геолокации, платежи и другие действия не нажимаются. Адрес, порт и тег по-прежнему сверяются по карточке; callback берётся только из ответа бота. Регрессия использует настоящие объекты закреплённой библиотеки без подключения к Telegram.

Ручное сохранение раньше блокировалось любым незавершённым заданием, даже неудачной начальной проверкой. Теперь подтверждённая владельцем связь может заменить задание с ошибкой в фазе `inspect`, пока внешнее изменение ещё не разрешено. Сохранение и отмена проверки выполняются одной транзакцией под общей блокировкой планировщика. Запоздалый ответ отменённого задания не может начать переключение. Фазы `bind` и `propagating` остаются заблокированы даже при ошибке: результат внешней записи может быть неизвестен.

Причины отказа при сохранении тега имеют отдельные коды и понятные тексты в кабинете. При ошибке поля сохраняются. Неудачная запись не отменяет проверку; аудит успешной ручной привязки содержит идентификатор заменённого задания, без тега. Подготовка канала по умолчанию не захватывает узел до назначения ожидающей кампании с уже сохранённой ручной связью.

Обновление устанавливается через «Профиль → Версия и обновления» вместе с хостовым агентом. Миграций нет. Повторный вход в Telegram не требуется, если сохранённая сессия действительна. Следующий проход агента после действующей паузы Telegram использует новый фильтр. Успешное сохранение тега не является подтверждением показа канала: применение проверяется по свежему отчёту агента, показ — отдельно в Telegram.
