# Карточки VPN

Справа от срока подписки видны дата и время последнего отклика. Под статусом указан тариф. Нажатие на статус открывает выбор нового состояния, карандаш — редактирование срока и лимита. У подтверждённых пользователей рядом с именем показаны синяя галочка, точка и состояние VPN.

В административной карточке для российского IP указан город, для зарубежного — страна и город. Определение выполняется локально по базе DB-IP City Lite.
