# Диалоги с Пушком

Предложите идею в Mini App или в чате поддержки Telegram. Когда Пушок задаст вопрос, ответьте в том же обращении. Для ответа модель получает первоначальную идею и последние реплики этого разговора.

Если предложение раньше автоматически получило статус «Ожидает сотрудника», обсуждение возобновится при следующем сообщении пользователя. По кнопке «Позвать сотрудника» вопрос передаётся команде вместе с перепиской.

Для свободного диалога включите «Ответы пользователям» в настройках подключения ИИ. Когда генерация недоступна, бот может задать несколько уточнений. Ответы доступны на русском, английском и испанском.
