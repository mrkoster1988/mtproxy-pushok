# Пополнение баланса

Во внешнем веб-кабинете откройте **Баланс → Мой кошелёк → Пополнить**. Platega принимает суммы от 10 до 10 000 ₽, СБП через Antilopay — от 20 до 10 000 ₽. Для Antilopay покупатель вводит email. Счёт появляется в списке пополнений, зачисление — в истории операций.

## Подключение магазина

Включите у Platega создание одноразовых платёжных ссылок с выбором способа на форме. Для проекта Antilopay подключите СБП. Реквизиты хранятся на сервере кабинета в закрытом файле `.env`.

| Способ | Переменные для API и sbp-worker |
|---|---|
| Platega | `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET`, `PLATEGA_ENABLED=1` |
| Antilopay | `ANTILOPAY_PROJECT_ID`, `ANTILOPAY_SECRET_ID`, `ANTILOPAY_PRIVATE_KEY_BASE64`, `ANTILOPAY_ENABLED=1`. Для ОСНО укажите применимую ставку в `ANTILOPAY_VAT`. |

Укажите публичное имя веб-кабинета в `PUSHOK_PUBLIC_PAYMENT_HOST` для возврата покупателя. Для приёма настоящих средств установите `PLATEGA_TEST_MODE=0` или `ANTILOPAY_TEST_MODE=0` у соответствующего магазина. Значение 1 отключает зачисление в кошелёк. Тестовые реквизиты предоставляет сам провайдер. Переключайте режим после сверки выставленных счетов. После установки версии примените изменения окружения командой `docker compose up -d api sbp-worker` из каталога кабинета.

Статус запрашивает фоновый обработчик, также доступна кнопка «Проверить пополнение». Повторная проверка использует ту же запись журнала. Для остановки выпуска новых счетов установите соответствующий флаг ENABLED в 0 и сохраните реквизиты для сверки. Полные возвраты и подтверждённые возвраты Antilopay отражаются в истории. Частичный возврат или оспаривание Platega помечается для ручной сверки в управлении балансами.
