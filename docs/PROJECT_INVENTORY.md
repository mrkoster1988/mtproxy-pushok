# Инвентаризация MTProxy Pushok — v1.24

Дата: 16 ноября 2026. База проверки: main `66ae913aecd62d7587b27525a4c80537cfc4d5cc` (v1.23), затем изменения v1.24. Это реестр проверенных областей и известных ограничений, а не обещание отсутствия любых ошибок.

## Исправленные несостыковки

| Область | Найдено | Исправление |
|---|---|---|
| Кошелёк | В Mini App главным показывался внутренний XTR; выбор двух валют пополнения | Главный RUB; новые пополнения СБП; прямые Stars отдельно |
| Старые средства | Удаление XTR могло потерять учёт/возвраты | Неизменяемый журнал, остатки, старые счета и возвраты сохранены; старый XTR виден при ненулевом остатке |
| Автосписание | Сохранялась авторизация внутреннего XTR | Новое включение XTR запрещено, миграция выключает старое; RUB сохраняется |
| Скидки | Снижали Stars одновременно с рублями | Stars сохраняет цену тарифа; только RUB получает скидку |
| Mini App | Промокод мог тратиться при оплате Stars | Промокоды отклоняются; автоматические скидки не применяются |
| Рефералка | Stars могли создавать награду | Новые награды только за успешный реальный SBP/RUB или внутреннюю RUB-оплату с денежной частью |
| Логотипы | Все каналы отображались общей иконкой | Авторизованный endpoint, getChat → getFile, безопасное изображение, кэш, fallback |
| Сверка СБП | Включение приёма из кабинета не включало фоновую сверку | Единый сохранённый флаг, сверка продолжает обработку старых счетов при отключении приёма |
| СБП | Некорректные типы приватной конфигурации могли вызвать 500 | Проверка структуры, отключение повреждённой интеграции без подмены ключа |
| Документация | README называл уже реализованные функции планами | Обновлены описание, дорожная карта, текущая модель бонусов |

## Ограничения и решения

- В Telegram цифровые услуги оплачиваются Stars; RUB/SBP — внешний веб-кабинет. Рублёвый остаток при этом виден в Mini App. [Правила Telegram](https://core.telegram.org/bots/payments-stars).
- Личный баланс Stars Telegram недоступен обычному Bot API. Кнопка открывает личные Stars; число из Telegram не выдумывается.
- Бонусные рубли учитываются отдельно для корректного возврата/аудита; это не другая валюта и не обмен Stars. Подарки не создают XTR.
- Старые цены заявок и уже выданные награды сохраняются. Новая модель применяется к новым расчётам/награждениям; отмена старой награды при возврате работает.
- После появления SBP-счетов смена магазина/окружения/домена блокируется, чтобы не смешать их сверку. Ротация ключа того же магазина возможна. Переход на другой магазин требует отдельного переноса с сохранением старой сверки.
- Ошибка загрузки аватара не подтверждает отсутствие канала и не меняет модерацию. Фотографии не дают прав на канал. API не выдаёт бот-токен и произвольные URL загрузки.
- Pushok ID и полноценное переключение альтернативного Rust-ядра в production не входят в завершённую основу MTProxy.
