# Иконка устройства рядом с IP

В кабинете откройте вкладку VPN и разверните карточку пользователя. Слева от последнего IP подключения отображается значок Android, iPhone или iPad, Windows, macOS либо Linux, если Shop сопоставил последнее подключение с загрузкой этого профиля. Если данных недостаточно, отображается значок вопроса.
