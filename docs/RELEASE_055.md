# v0.055 — одна заявка от проверки до завершения

В «Управление → Модерация» выберите заявку. Дальше оставайтесь в её карточке:

1. Откройте канал и одобрите его либо заполните причину исправлений/отказа.
2. Дождитесь автоматического подтверждения Stars/СБП. Для ручного чека проверьте файл и фактическое поступление денег.
3. Выберите узел и время. Для одного активного узла выбор подставляется автоматически; часовой пояс подписан.
4. Включите тег вручную, проверьте спонсора в отдельном аккаунте без подписки на канал и заполните наблюдение. Одна кнопка сохраняет наблюдение и запрашивает активацию. Если второй запрос не прошёл, карточка сообщает о частичном результате.
5. После выключения тега и проверки отсутствия спонсора подтвердите завершение.

Бесплатный тариф пропускает оплату после одобрения. Кнопки не подтверждают показ или поступление денег сами: API проверяет роль, состояние, окно размещения и наблюдение. Автоматическое переключение тега не добавлено.

История, файлы и CSV свёрнуты внизу. В Telegram основная кнопка открывает одну форму заявки. Без настроенного Mini App сохраняется старый мастер. Доступ к карточкам оператора проверяется сервером.

Обновление устанавливается кнопкой «Настройки → Система → Установить обновление». После установки заново откройте Mini App и отправьте /start боту, чтобы получить новое меню. Настройки домена и ключи хранятся отдельно.

Если на VPS вручную исправляли `scripts/repair_proxy.py` по инструкции из чата, прежний обновлятор остановится из-за локального изменения. Один раз сохраните правку командой `cd /opt/mtproxy-pushok && git stash push -m pushok-repair-before-v055 -- scripts/repair_proxy.py`, затем установите обновление кнопкой. Исправление уже входит в v0.055; сохранённую копию возвращать поверх новой версии не нужно. Остальные локальные изменения обновлятор по-прежнему не перезаписывает.
