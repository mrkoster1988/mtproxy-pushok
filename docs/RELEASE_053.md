# v0.053 — бесплатный тариф администратора

Обновление: **Настройки → Система → Установить обновление**. Если служба ещё
не установлена, нужна [однократная настройка](RELEASE_051.md).

После обновления в кабинете и Mini App у администратора появится тариф
**«Администратор · Бесплатно»** с пояснением о доступе только для администраторов. Выберите его при
создании заявки. По умолчанию срок — 24 часа, стоимость — 0 ₽. После обычной
модерации оплата не требуется; счета Stars и СБП не создаются.

В **Настройки → Тарифы** можно изменить название, длительность и включение
тарифа для новых заявок. Цена закреплена на нуле, Stars отключены. Изменения
срока не пересчитывают уже созданные заявки. Повторное обновление не сбрасывает
настройки и не создаёт дубль тарифа.

Обычные пользователи и операторы не видят служебный тариф и не могут выбрать
его через API. Роль проверяется на сервере для действующей сессии; после снятия
роли admin новые заявки по служебному тарифу недоступны. Публичный каталог,
цена на главной странице и стандартный тариф бота служебный тариф не включают.
Создавать служебные заявки нужно через кабинет или Mini App.

Миграция `023_admin_free_tariff.sql` добавляет признак `admin_only`, ограничение
нулевой цены и проверку роли владельца при вставке/переназначении кампании.
Публичные бесплатные тарифы, созданные ранее, сохраняют свою доступность.
