# v1.21 — восстановление обновлений

Обновлятор ожидает освобождения host-lock, затем заново проверяет очередь. Финализатор при занятой блокировке не изменяет состояние другого процесса. Таймер раз в минуту запускает проверку: сохранённый запрос обрабатывается, а оставшийся без процесса статус running становится failed. Завершённые и неудачные установки без нового запроса повторно не устанавливаются.

Служба ограничивает общее время одним часом, каждый внешний шаг — 30 минутами. Блокировка исключает параллельную установку. При обновлении автоматически переустанавливаются systemd units, включая таймер. Отдельная установка: `sudo bash /opt/mtproxy-pushok/scripts/install_updater.sh --install-only`.

Профиль → Версия и обновления различает ожидание запуска и выполнение. В ожидании показывается время запроса, через две минуты появляется пояснение о задержке. Автоматический возврат базы не выполняется: сбой требует проверки журнала, чтобы не потерять новые операции.
