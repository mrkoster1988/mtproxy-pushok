# v1.107 — Модераторы и отметка «Друзья»

Модератор разбирает спорные заявки в разделе «Модерация». Снять ограничение с канала может оператор или администратор.

В карточке пользователя можно поставить отметку «Друзья». Она совместима с любой назначаемой ролью и не даёт дополнительных прав.

Чёрный список каналов учитывает ещё три подтверждённых нарушения — сексуальную эксплуатацию несовершеннолетних, торговлю людьми и публикацию чужих персональных данных для травли. Аккаунт рекламодателя сохраняет доступ к кабинету.

Для назначения откройте «Профиль → Пользователи», выберите пользователя и нажмите на его роль. Модератор может одобрить чужую спорную заявку, запросить исправления или отклонить её с причиной.

Миграция 072 сохраняет существующие роли. У существующих пользователей отметка «Друзья» по умолчанию выключена.
