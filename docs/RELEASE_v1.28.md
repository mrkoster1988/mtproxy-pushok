# v1.28 — надёжный запуск Mini App

При входе приложение раньше загружало JavaScript SDK с `telegram.org`.
Если этот внешний запрос не завершался за 8 секунд, клиент видел ошибку
«Не удалось загрузить Telegram» и не мог войти, хотя сам кабинет был доступен.

Теперь неизменённая копия официального SDK поставляется вместе с кабинетом
и загружается с того же домена. Версия файла закреплена контрольной суммой;
исходный адрес и лицензия находятся в `api/web/vendor/TELEGRAM-NOTICE.md`.
Проверка подписи Telegram на сервере, права доступа и платежи не ослаблены.
Миграций базы данных нет.

Браузерные регрессии используют настоящий SDK и API с временной PostgreSQL.
Внешние запросы заблокированы; имитируется только нативный мост клиента
Telegram. Проверяются первый вход нового рекламодателя, повторное открытие,
кнопка «Назад», отступы, отмена синтетического счёта Stars, ошибка и тайм-аут
загрузки SDK с успешным повтором. Вне Telegram доступ не предоставляется.

Обновление устанавливается через **Профиль → Версия и обновления**.
После установки клиенту нужно полностью закрыть Mini App и открыть его
кнопкой бота. Публикация версии не подтверждает установку на VPS или
повторную проверку на конкретном устройстве клиента.
