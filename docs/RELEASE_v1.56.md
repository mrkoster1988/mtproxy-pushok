# v1.56 — Выбор прокси из списка MTProxyBot

На скриншоте пользователя @MTProxyBot показывает прокси кнопкой «IP + 32-символьный тег», без порта. Агент сопоставлял только адрес с портом и ошибочно возвращал «Прокси не найден в аккаунте владельца». Каждые пять минут очередь повторяла тот же запрос.

Теперь агент распознаёт и этот формат. Совпадение адреса лишь позволяет открыть карточку: перед Set promotion по-прежнему обязательны точный адрес и порт карточки, однозначный тег и совпадение с тегом списка. При нескольких подходящих записях агент останавливается. Секрет подключения не принимается за тег.

У приостановленной заявки кнопка «Возобновить автоподбор» вынесена на видное место. Снятие ранее назначенного слота намеренно ставит автоподбор на паузу; возобновление выполняется явно.

## После установки

1. Обновите проект через «Профиль → Версия и обновления».
2. В модерации откройте приостановленную заявку и нажмите «Возобновить автоподбор». В старом интерфейсе эта кнопка находится внутри «Изменить расписание».
3. В «Узлы и спонсоры → Настройка» дождитесь очередной попытки агента. Повторно регистрировать существующий прокси не требуется.

При успешной проверке привязки система выдерживает паузу обновления Telegram и назначает полный период. Состояние подключения аккаунта само по себе не подтверждает показ спонсора.

## Проверки

Регрессионные тесты воспроизводят показанный формат списка, неверный порт, отсутствие порта в карточке, смену тега, похожий адрес, дубликаты, неподдерживаемые кнопки и повторное чтение после Set promotion. Chromium проверяет видимость кнопки возобновления и фактическое снятие паузы через API и отдельную PostgreSQL.

Тестовые диалоги синтетические. Подключение к живому @MTProxyBot и установка на VPS в этой проверке не выполняются.
