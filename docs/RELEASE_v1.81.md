# v1.81 — Английский оригинал карточки MTProxyBot

Агент не читал тег из фактического ответа `Proxy host:port with the tag <32 hex>.`, поскольку v1.77 ожидала двоеточие после `Proxy` или `Proxy server`. Теперь двоеточие допускается, но не требуется. Старые карточки и русские переводы поддерживаются.

В регрессиях используется английский текст карточки со скриншота с заменёнными адресом, тегом и ссылкой. Проверены полный тег с завершающей точкой, перенос строки, верхний регистр, скрытая ссылка на канал, переключение через `Edit promotion` и повторная проверка без переключения уже назначенного канала. Сокращённый тег из подсказки, secret, неверный адрес/порт и конфликтующие теги отклоняются.

Миграций и новых разрешений нет. Установка через «Профиль → Управление → Версия и обновления». Telegram-сессия сохраняется. Привязка на VPS считается подтверждённой только после свежего успешного ответа агента; локальные тесты используют подменённые ответы Telegram.
