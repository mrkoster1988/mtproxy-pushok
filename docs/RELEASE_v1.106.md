# v1.106 — Очередь кампаний и резервный канал

При ожидании запуска кабинет сохраняет срок кампании, даже если у резервного канала ещё нет тега.

Пока агент не начал менять привязку в Telegram, ближайшая готовая к подготовке заявка получает приоритет над резервом.

О нехватке тега резервного канала бот сообщает сотрудникам в разделе диагностики узлов.
