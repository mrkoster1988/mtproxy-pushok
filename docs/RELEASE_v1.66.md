# v1.66 — Проверка признаков 18+ с обоснованием

В карточке «Модерация → Заявка → ИИ-помощник → Разобрать заявку» появился отдельный блок «Контент 18+». Это оценка доступной текстовой выборки для сотрудника. Тематика «18+ · Для взрослых» из v1.64 сохраняется как самостоятельное поле кампании; проверка не перезаписывает выбор рекламодателя и не принимает решение модерации.

| Результат | Что означает |
| --- | --- |
| Нужна проверка 18+ | ИИ обнаружил возможные признаки либо найдена явная маркировка. Нужно проверить фрагменты и их контекст. |
| Признаки 18+ не выявлены | Модель не нашла признаков в просмотренных текстах. Это не оценка всех публикаций или медиа. |
| Недостаточно данных для вывода | Публикации недоступны, ИИ не смог оценить их или ответ не прошёл проверку. Требуется ручная проверка. |

## Как использовать

Обновите кабинет через «Профиль → Версия и обновления». Владельцу: при подключённом OpenAI включите разрешение «Анализировать заявки и готовить комментарии» в «Настройки → Система → ИИ · Возможности». Нового разрешения, API-ключа или перезапуска для существующего подключения не требуется. Старые настройки, разрешающие только тематику, не получают доступ к разбору заявок автоматически.

Откройте помощника в заявке и нажмите «Разобрать заявку». Под результатом показаны количество доступных текстов и источник оценки: ИИ или локальная проверка маркеров. «На чём основан вывод» раскрывает до трёх фрагментов с названиями источников. Проверяются название, описание и до восьми доступных публичных текстовых публикаций.

## Как проверяется ответ

- Ответ модели проходит строгую схему. Каждая цитата сопоставляется с конкретным загруженным источником. Если цитата выдумана, источник отсутствует или для замечания нет подтверждения, весь ответ модели отклоняется, включая черновик комментария.
- В интерфейс попадает фрагмент исходного текста с окружением, а не произвольная цитата модели. HTML и инструкции из публикаций показываются обычным текстом.
- Маркировки `18+`, `+18`, `🔞`, `NSFW` и связанные слова вызывают подсказку о ручной проверке даже при сбое ИИ. Маркеры сами по себе не доказывают взрослую тематику: они могут встречаться в новостях, медицине, образовании и запретах.
- Отсутствие доступных публикаций не позволяет показать результат «Признаки 18+ не выявлены». При недоступном канале сохранённое название не используется как доказательство содержимого.
- Фото, видео и закрытые публикации не анализируются. Проверка не гарантирует обнаружение всех признаков 18+.

Проверка выполняется внутри существующего запроса разбора заявки: отдельного обращения OpenAI нет. Увеличен предел длины ответа с 1000 до 1500 токенов для цитат; стоимость зависит от выбранной модели и фактического использования. Содержимое и ответы не сохраняются в БД или журнале аудита. В аудит попадают только вид запроса и источник результата. Права, оплата, бонусы, расписание и модерация остаются под контролем штатных форм.

## Проверки

Автотесты проверяют явные маркеры, контекст отрицаний и образовательных материалов, недоступность публикаций, выдуманные цитаты, ограничения длины, отказ провайдера, отсутствие изменений заявки и сохранения текстов в аудите. Chromium проверяет три состояния результата, раскрытие фрагментов, безопасное отображение HTML, черновик, выход во время запроса и мобильные ширины 320/390/768/1280 px.

Внешний ответ OpenAI заменён тестовым. Проверки не используют живой API-ключ и не подтверждают обновление VPS или качество выбранной модели на реальных каналах.
