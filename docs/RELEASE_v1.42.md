# v1.42 — каналы в списке кампаний

Username в карточках кампаний стал прямой ссылкой на Telegram. После временного сбоя аватарки повторно запрашиваются при обновлении списка вместо сохранения пустого результата на весь сеанс. Увеличено время ожидания ответа Telegram для фотографий с 2 до 8 секунд.
