# v1.26 — плавное обновление и статус автоматики

Обновление доступно через **Профиль → Версия и обновления**. Публикация версии не означает её установку на VPS.

## Изменения

На записи экрана при опросе API баланс заменялся меньшим блоком «Загружаем остаток…». Теперь данные обновляются на месте; ошибка связи сохраняет прежний остаток с отметкой «не обновлён». Неизменившиеся карточки не пересоздаются фоновым опросом. Открытый отчёт и панель автоматики сохраняются при изменении статуса кампании.

Кнопка **Автоматика** показывает состояние серверного размещения вместо отчёта о визуальном наблюдении оператора. Назначенный период не выдаётся за подтверждение запуска: запуск подтверждает агент после применения тега, завершение — после его снятия или смены. При отсутствии ответа отображается проблема связи. Пропущенный без запуска период не считается отработанным.

Для автоматики требуется подготовленная связь канала со спонсорским тегом и работающий агент. Дополнительные наблюдения в Telegram сохранены в раскрываемом блоке отчёта; они не являются обязательным шагом автозапуска. Счётчик просмотров не добавлялся.

Выпуск сохраняет платёжную модель v1.24, историю и ручные резервные операции администратора. Миграций БД нет.

## Проверка

Регрессии браузера проверяют геометрию экрана во время задержанного ответа баланса, повторный опрос без пересоздания карточек, ошибку связи, сохранение открытого отчёта и обновление статуса агента. Тесты API проверяют серверные границы периода, отсутствие ответа, подготовку канала, завершение и права доступа. Реальные платежи и управление VPS в тестах не выполняются.
