# v1.87 — Формы и история кампании

Продолжение правок кабинета по мобильным снимкам владельца. Версия сохраняет единый вход и подготовку первого резерва из v1.84/v1.86.

- В редакторах канала, кампании и узла сохранение и отмена стоят справа от поля с одинаковым размером кнопок и интервалом. Обработчики форм и серверные проверки остаются прежними.
- Копирование черновика ИИ и вставка в комментарий расположены справа от текста. Вставка только заполняет форму: решение модератора не отправляется автоматически.
- «История и документы» загружает сведения при открытии. Сбой показан внутри блока с кнопкой повторной загрузки. При ошибке обновления прежние сведения остаются видны с отметкой об ошибке. Запоздавшие ответы не заменяют более свежую загрузку.
- Журнал проверок состоит из компактных записей: результат, дата, комментарий и действие со скриншотом. Прикрепление стоит справа от выбора файла. После успешной загрузки оно заменяется скачиванием; права на файлы проверяет API.
- Обновлены номер версии и адреса изменённых ресурсов, чтобы Mini App получил новые стили и значки после переоткрытия.

Проверки включают настоящий API и отдельную PostgreSQL, недоступный отчёт, повторную загрузку, сохранение предыдущего отчёта, мобильную геометрию, прикрепление и скачивание скриншотов. Внешние платежи и рабочий VPS в этих проверках не участвуют. Статус GitHub и старых PR зафиксирован отдельно: [аудит](GITHUB_AUDIT_v1.87.md).
