# v1.87 — Аудит GitHub и исправления

Проверка 17 ноября 2026 года. Исходная версия: `08a7d702585437850b5da2578cea36aa5a7233d6` (v1.86).
На момент проверки `main` и `release/stable` указывали на этот коммит. Проверены все 150 удалённых веток,
все открытые PR, последние результаты Actions, замечания ревью PR #133–157 и затронутый ими текущий код.
Ветки, не являющиеся предками main после squash/rebase, сами по себе не означают конфликт или потерю изменений.

## Исправления текущего кода

| Область | Ошибка | Исправление |
| --- | --- | --- |
| Общий вход | Основной MTProxy на 443 отклонялся | Диапазон портов backend — 1–65535; требования к портам слушателя сохранены |
| Общий вход | Заглавные hex-символы рабочего `-S` считались другим ключом | Сравнение проверенных hex-ключей без учёта регистра |
| Общий вход | Порт узла на чужом VPS мешал сохранению | Проверка портов по локальному адресу и алиасу из файлов агента; реальная проверка сокетов перед запуском сохранена |
| Помощник | Обновление через 20 секунд отменяло незавершённый анализ | Фоновое обновление откладывается до завершения запроса; выход по-прежнему отменяет его |
| Автомодерация | Медиа пропадали из выборки текстов | Фото, видео, другие медиа и неполные тексты направляют заявку сотруднику; анализ охватывает только последнюю выборку, не весь канал |
| Автомодерация | Старые повторы вытесняли новые заявки | Сначала непроверенные, затем наименее недавно проверенные заявки |
| Профили | Для каждого аватара выполнялись четыре глобальных рейтинговых запроса | Общий расчёт первых 10 мест на БД и месяц с TTL 20 секунд, ограниченным кэшем и защитой от одновременных расчётов |
| Архив | Закрытые общие расходы пересчитывались после возврата/блокировки | Старые рублёвые и Stars-номинации читаются из сохранённых итогов раздельно; новые начисления не создаются |
| Призы | Сумма двух допустимых старых призов не проходила новую форму | Для объединённой номинации предел 200 млн копеек; общий бюджет и пределы остальных номинаций сохранены |
| Обновление БД | Миграция 056 могла выбрать заблокированного первого администратора | Новая 062 исправляет именно этот первоначальный выбор или отсутствие владельца; активный владелец и блокировка прежнего аккаунта сохраняются, изменение записывается в аудит |

Миграции 001–061 не изменены: журнал контрольных сумм сохраняет совместимость обновления.
Уже исправленное в v1.85 явное «Не указывать» для тематики проверено отдельно: выбор того же значения
отправляет событие и отменяет ожидающую автоматическую подсказку.

## Проверки и ограничения

- Исходный main: [Actions 44164053151](https://github.com/mrkoster1988/mtproxy-pushok/actions/runs/44164053151) — success; release/stable: [44164094236](https://github.com/mrkoster1988/mtproxy-pushok/actions/runs/44164094236) — success. Старые красные запуски не приписываются текущему SHA.
- Локально: 1169 unittest с отдельной PostgreSQL, 10 пропусков из-за Docker/HAProxy; 11/11 preflight и 3/3 offline release checks. Браузерные сценарии и полный CI нового SHA проверяются в PR этого исправления.
- В GitHub `main` и `release/stable` имеют `protected=false`, список repository rulesets пуст. Рекомендуется требовать PR и успешные `test`, `cabinet-preview`, `rust-core`, `compose-smoke` перед слиянием. Настройки доступа этим исправлением не менялись.
- Проверка исходников и CI не подтверждает установку v1.87 на VPS, живую регистрацию Telegram, фактический показ спонсора или реальные платежи. Это не полный аудит всех исторических веток или независимый аудит безопасности.

Обновление на VPS — штатной кнопкой кабинета с резервной копией. После установки проверьте общий вход,
ИИ-разбор при открытой карточке и доступ владельца. Следующий отдельный этап: адаптация #89 и разбор
устаревших интеграционных PR без возврата старого интерфейса и схемы БД.
