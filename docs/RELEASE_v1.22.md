# v1.22 — компактный Mini App

Обновление интерфейса действующего кабинета без изменений БД и API.

## Что изменилось

- Четыре основных раздела: главная, кампании, баланс, профиль. Каналы, календарь и архив доступны внутри кампаний.
- Главная: короткий баннер, действительный баланс и до двух кампаний, приоритет у требующих действия.
- Кампании: три статуса в одной строке, компактная цена и период, открытие по стрелке. Дополнительная кнопка появляется только для следующего действия.
- Новая кампания: поля без повторных заголовков и декоративного степпера; дата и промокод раскрываются отдельно.
- Баланс: история операций видна сразу, пополнение, подарок и автооплата раскрываются по нажатию. Состояние раскрытых блоков сохраняется при обновлении текущей сессии, сбрасывается при выходе.
- Профиль: кабинет, управление и поддержка сгруппированы; длинный общий список заменён короткими группами.
- Основной текст 13–15 px, заголовки страниц 20–22 px, кнопки с областью нажатия от 44 px. Иконки имеют aria-label и title.

## Проверка

Сценарии PostgreSQL и браузера проверяют создание заявки, цены/скидки, оплату, возвраты, подарки, права ролей, обновления, навигацию и ширину 320/390/1280 px. Добавлены проверки компактных карточек и раскрытия операций баланса.

После установки переоткройте Mini App. Версия frontend-ресурсов обновлена для сброса кэша. Статусы размещений остаются серверными; счётчик показов не имитируется.
