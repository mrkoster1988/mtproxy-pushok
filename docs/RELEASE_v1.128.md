# MTProxy Pushok v1.128 — автоматические релизы и обновления

Эта версия включает программную автоматизацию:

- GitHub Actions переводит `main` в `release/stable` **только** после
  успешных Python/PostgreSQL, Rust, Compose и браузерных тестов текущего SHA.
- Пропущенный или красный CI, конфликт историй, отставший SHA и принудительное
  обновление ветки запрещены.
- Отдельная команда `scripts/enable_auto_updates.py install` на VPS включает
  существующий системный updater. Часовой цикл делает приватный бэкап,
  обновляет только опубликованную стабильную версию, проверяет миграции и
  доступность компонентов.
- Скрипт установки отказывается перезаписывать чужие systemd-службы и
  сохраняет остальные приватные настройки.
- Регрессионные проверки гарантируют, что тестовое подключение статистики
  кампаний использует корректный ответ Telegram без зависимости от порядка
  конкурентных вызовов. Проверка реальных прав бота не ослаблялась.

**Разделяйте** публикацию версии, её установку на VPS и реальный тест
подключения Telegram. Полный перечень команд —
[Автоматические релизы](AUTO_RELEASES.md). Реальные ключи и .env не публикуются.
