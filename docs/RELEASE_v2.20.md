# Напоминание о первом подключении

В настройках VPN видна последняя подтверждённая отправка напоминания о первом подключении. Рассылка учитывает пользователей, которые ещё ждут первый профиль. Если Telegram ранее заблокировал доставку, команда /start в личном чате снова разрешает плановые напоминания. В карточке можно заново выбрать срок после истечения попытки восстановления.
