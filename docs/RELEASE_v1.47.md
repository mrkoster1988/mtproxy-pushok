# v1.47 — аналитика кампаний

В карточке и отчёте доступны охват отдельной ссылки, переходы, подписки, конверсия и история по дням. Владелец включает подсчёт кнопкой после добавления бота администратором канала. Приложение создаёт приглашение и страницу ссылки; бот автоматически учитывает вступления по приглашению, без повторного начисления событий.

Охват спонсорского блока MTProxy остаётся недоступным: показатели ссылки нельзя выдавать за его показы. Подробности, ограничения и подключение — в [документации аналитики](CAMPAIGN_ANALYTICS.md).

Добавлена миграция 048. Проверка на настоящем Telegram и VPS выполняется после установки; локальные тесты используют изолированную БД и замену Bot API.
