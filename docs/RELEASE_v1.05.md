# v1.05 — удалённые заявки

После удаления одобренная заявка с незавершённым счётом могла оставаться в модерации без отметки об архиве. Это выглядело как неработающая кнопка удаления.

Теперь рабочая очередь не содержит архивных заявок. Для оставшихся платежей, чеков и активных показов есть свёрнутый раздел «Удалённые: требуют завершения». При открытии указаны дата удаления и незавершённое действие. Из «Профиль → Удалённые» можно открыть такую карточку или восстановить заявку.

Удаление не списывает и не возвращает деньги, не отменяет счёт у провайдера и не отключает работающий прокси. История сохраняется. После закрытия всех оставшихся действий заявка остаётся только в архиве. Восстановление не запускает размещение автоматически.

## Установка и проверка

1. Профиль → «Версия и обновления» перед котом → «Проверить» → «Установить обновление».
2. Убедиться, что установлена v1.05. Перезагрузить мини-приложение.
3. Уже удалённая заявка исчезнет из рабочей очереди без повторного удаления. Если она ещё не удалена: Модерация → заявка → «Изменить или удалить заявку» → «Удалить».
4. Проверить «Профиль → Удалённые». При незавершённой оплате карточка также доступна в отдельном свёрнутом разделе модерации.

Регрессии покрывают ожидающую оплату с созданным/ожидающим счётом, повторное удаление, закрытие счёта, проверку чека, активное размещение, восстановление и ограничения доступа. Браузерный сценарий удаляет заявку через кнопку, обновляет и перезагружает страницу, открывает архив и восстанавливает запись.

Схема БД не изменяется. Данные на конкретном VPS проверяются после установки.
