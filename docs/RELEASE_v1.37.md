# v1.37 — лицензия владельца приложения

Владелец установленной копии покупает лицензию в Профиле → «Лицензия приложения». Рекламодателям лицензия приложения не нужна. У центрального продавца настраиваются тарифы, срок, цена в Stars и лимиты узлов, администраторов и незавершённых кампаний.

Оплата подтверждается ботом продавца; установка получает подписанный статус, обновляемый автоматически. Купленные условия фиксируются. Продление добавляет следующий период, возврат отзывает связанный период, повторные уведомления не увеличивают срок. При истечении лицензии ограничиваются новые операции, а история и оплаченные размещения сохраняются.

Обновление добавляет миграцию `045_application_licenses.sql`. Существующие установки по умолчанию продолжают работу без лицензирования. Для продажи и поставки лицензируемых копий нужна [настройка продавца и клиента](APPLICATION_LICENSES.md). Ключи включены в полную резервную копию.

Проверки включают API/PostgreSQL, конкурентные лимиты, подписи, платёжные регрессии, интерфейс администратора на 320/390 px и покупку с синтетическим платёжным провайдером. Реальная продажа требует настроенного сервера и контрольной покупки на VPS.
