# v1.110 — Модератор и оператор

Модератор может пересматривать решения операторов до начала оплаты и планирования размещения. Причина пересмотра сохраняется и отправляется рекламодателю.

Назначать модераторов и управлять их доступом может администратор. Оператор может снять канал с чёрного списка.

Доступные для пересмотра заявки видны модератору в разделе «Модерация → Решения операторов». Миграция 073 добавляет представление очереди.
