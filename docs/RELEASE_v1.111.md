# v1.111 — Приглашение к прокси

Личная ссылка и QR-код открывают подключение к действующему прокси в Telegram. Публичный адрес кабинета берётся из настройки `PUSHOK_MINIAPP_URL`. Старые ссылки через бота продолжают работать.

При входе в кабинет из того же браузера приглашение засчитывается автоматически. В другом браузере можно указать код до первой заявки. Условия награды за размещение сохраняются.
