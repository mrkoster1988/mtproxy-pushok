# MTProxy Pushok — актуальная дорожная карта

Обновлено 13 ноября 2026. Базовая версия исходников — v0.050, последующие изменения перечислены в [CHANGELOG](../CHANGELOG.md) как Unreleased. Основной репозиторий и CI — **GitHub**. GitLab исключён из текущего процесса.

Цель: платформа спонсорства каналов в Telegram через MTProxy — бот, кабинет/Mini App, модерация, оплата и подтверждённое размещение. Базовый тариф 1 день — 300 ₽ настраивается; RUB и XTR учитываются отдельно. Вход MTProxy остаётся через Telegram.

## Что подтверждено

- В исходниках есть API/PostgreSQL, бот, кабинет, Mini App с проверкой initData, тарифы, кампании, модерация, слоты, ручное подтверждение спонсора, отчёты и установщик с диалогом.
- Реализованы серверные потоки Stars и СБП, идемпотентность и сверка. Наличие кода **не означает** приёмку живых платежей и возвратов. Коммерческие флаги по умолчанию выключены.
- GitHub Actions снова выполняется. Для исходной точки этого пакета `b4722bc4165baae96924e5db90b19c8763ea666a` подтверждён [успешный запуск 43337955622](https://github.com/mrkoster1988/mtproxy-pushok/actions/runs/43337955622): API/PostgreSQL, Compose smoke, Rust и браузерные сценарии. Каждый следующий коммит требует собственного успешного CI.
- Репозиторий публичный по решению владельца. Это не разрешение автоматически открыть кабинет или развернуть production.

## Пакет из 10 шагов: подготовка установки к приёмке

Этот пакет продолжает пункты установщика, безопасности и эксплуатационных проверок. Он не закрывает живые испытания VPS/Telegram.

| № | Изменение | Проверка результата |
|---|---|---|
| 1 | Актуализированы план, критерии выпуска и статусы; история отделена | Действующие документы не объявляют старую блокировку CI текущей |
| 2 | Убраны GitLab CI и требования зеркалирования из действующих проверок | `scripts/preflight.py` проверяет GitHub; API предлагает подтвердить CI на SHA версии |
| 3 | Защищено чтение `.env` | Отклоняются символьные ссылки, чужой владелец, права шире 0600/0400 и файл в индексе Git |
| 4 | Добавлен строгий разбор конфигурации без исполнения | Дубли, неверные кавычки, подстановки и некорректный синтаксис дают ошибку без печати значений |
| 5 | Проверяются обязательные секреты | Заглушки, короткие/одинаковые секреты и неверный внутренний ключ отклоняются |
| 6 | Проверяются параметры БД и локального API | DSN совпадает с POSTGRES_*, адрес — db:5432; порт и имя Compose валидны |
| 7 | Проверяются Telegram и Mini App | Формат токена/username, флаги 0/1 и HTTPS URL `/miniapp`; без ложной проверки прав бота/администратора |
| 8 | Проверяются зависимости СБП | Провайдер и домен обязательны при включении; webhook требует сверки, а остановка выдачи счетов не запрещает сверку |
| 9 | Проверяется итоговый Docker Compose | Учтён override установщика, исключены внешние env overrides, API на localhost, БД/бот/worker без открытых портов; таймаут и скрытый stderr |
| 10 | Добавлены JSON-отчёт, инструкции и автоматические проверки | Регрессионные unit-тесты и отдельный CI-тест с настоящим Compose и искусственными секретами |

Команды и расшифровка ошибок: [STAGING_PREFLIGHT.md](STAGING_PREFLIGHT.md). Статус CI конкретного изменения проверять в его pull request; зелёный локальный preflight не является разрешением коммерческого запуска.

## После приёмки основы

Новые продуктовые функции вводятся после закрытия выпускных критериев; сейчас допустимы исправления, тесты, безопасность, установщик и инструкции.

1. Автоматическое назначение и переключение спонсора — после испытания применения и отката тега.
2. Акции, промокоды, купоны, скидки за длительность и рефералка: единый серверный расчёт и снимок цены, лимиты, защита от повторного начисления.
3. Внутренний баланс: журнал операций, раздельные RUB/бонусы/XTR, резерв/списание/отмена, история и сверка.
4. Pushok ID: автосоздание/привязка пользователя после Telegram-входа; возможный общий кошелёк. Pushok ID не становится обязательным способом входа MTProxy.
5. Продажа новых Stars — отдельный модуль только после подтверждения поставщика, разрешения на перепродажу, API и доступного приёма оплаты. Не выкуп личного остатка XTR.
6. Pushok Edge Glow в кабинете — [Issue #38](https://github.com/mrkoster1988/mtproxy-pushok/issues/38), с reduced motion и проверкой мобильных устройств.

Подробности: [PROMOTIONS_AND_WALLET.md](PROMOTIONS_AND_WALLET.md). Старые версии и решения сохранены в [ROADMAP_HISTORY.md](ROADMAP_HISTORY.md); они не подменяют этот план.
