# MTProxy Pushok v1.13

- Убраны стандартные светлые рамки fieldset вокруг форм настроек. Состояния disabled и обводка клавиатурного фокуса сохранены.
- Исправлено переключение последовательных кампаний на одном узле: после успешного ACK агент сначала завершает истёкшую активную кампанию, затем активирует следующую в той же транзакции. Устаревший ACK не меняет состояния.
- Если оплаченная одобренная кампания так и осталась запланированной и её период прошёл, после свежего ответа агента планировщик назначает новый свободный период полной длительности. Оплата сохраняется, новый счёт не создаётся. При ручной паузе или архивировании перенос не выполняется.
- Завершённые кампании автоматически переносятся в «Профиль → Архив → Завершённые кампании», включая ранее завершённые записи. История, оплата, отчёт и экспорт CSV сохраняются. Повторной рассылки старых завершений при обновлении нет.
- Telegram-уведомление о завершении открывает отчёт в архиве. Администраторы и операторы могут читать отчёт архивной заявки; посторонний рекламодатель доступа не получает.

После установки текущие слоты переключаются агентом; пропущенные заявки подбираются фоновым планировщиком после восстановления связи. Готовность конкретного VPS подтверждается только его состоянием и проверкой после обновления.
