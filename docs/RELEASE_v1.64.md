# v1.64 — Тематика 18+ и подключение OpenAI

В каталог добавлена «18+ · Для взрослых». До этого такой категории не было: ни правила, ни модель не могли её вернуть. Новая тематика доступна в форме, сохраняется в кампании и отображается рекламодателю и оператору.

Название `+18 Only sex stickers😈😉❤️` распознаётся по сочетанию возрастной маркировки и сексуальной тематики. Для явных признаков в названии/описании не нужны публикации канала или ключ OpenAI. Неопределённый ответ модели не стирает такую подсказку. Одна отметка 18+ у новостей, медицинское просвещение или одна посторонняя рекламная публикация сами по себе не определяют тематику взрослого контента. Это подсказка, а не разрешение рекламы или результат модерации; ручной выбор остаётся доступен.

Миграция `055_adult_channel_topic.sql` расширяет допустимые значения, сохраняет существующие кампании и допускает повторное выполнение. Обновление применяет её стандартным установщиком.

## Уже есть ChatGPT

Текущий кабинет использует ключ OpenAI API. Ссылка на профиль ChatGPT и статистика его токенов ключом не являются.

1. Откройте [API Platform](https://platform.openai.com/) тем же аккаунтом. Для подходящей подписки Pro или Business проверьте API-кредиты в ChatGPT → Настройки → Оплата либо в Billing на API Platform. Льгота требует активации для API-организации; доступность зависит от условий подписки.
2. Создайте [ключ API](https://platform.openai.com/api-keys) в проекте этой организации. Вводите его только в закрытую форму настроек своего кабинета, не публикуйте в чате или репозитории.
3. В puShok откройте **Профиль → Настройки → Система → ИИ · Возможности**. Вставьте ключ, нажмите **Проверить**, включите ИИ и разрешение **Предлагать тематику канала**, затем нажмите **Сохранить**. Поле ключа после сохранения очищается; ключ остаётся на сервере.

Официальная документация: [API-кредиты для подписчиков ChatGPT](https://developers.openai.com/api/docs/guides/chatgpt-api-credits), [создание ключа и первый запрос](https://developers.openai.com/api/docs/quickstart). Запросы расходуют баланс API-проекта, включая доступные кредиты. Прямой вход через ChatGPT в этой версии не реализован.

Проверки используют отдельную PostgreSQL и подмену внешних ответов Telegram/OpenAI. Они покрывают пример из обращения, отсутствие ложных срабатываний в контрольных случаях, сохранение кампании, отображение оператору, миграцию, выбор в форме и приоритет ручного выбора. Платный API и рабочий VPS при разработке не использовались.
