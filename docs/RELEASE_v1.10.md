# MTProxy Pushok v1.10

- Исправлено завершение старых активных кампаний, запущенных до появления события автоматической активации. После успешного снятия/смены тега агент завершает истёкшие кампании на своём узле; устаревший или неуспешный ответ не меняет статус.
- «Настройки → Система → Канал по умолчанию»: выбор канала свободного периода и подготовка его тега для выбранного узла.
- Текущая рекламная кампания имеет приоритет над каналом по умолчанию. После неё агент возвращается к выбранному каналу. Если канал по умолчанию не задан, возвращается исходный тег из конфигурации прокси.
- Настройка требует действующего тега этого канала для каждого узла. Теги не возвращаются браузеру. При отсутствии/изменении привязки диагностика показывает причину.
- Новый режим default не создаёт рекламную заявку, не принимает оплату и не имеет оплаченного срока. Сохраняется исходная конфигурация для отключения режима и отката.

После установки обновления следующий успешный цикл агента обработает и ранее зависшие истёкшие кампании. Обновление на VPS и фактическое отображение канала в Telegram проверяются отдельно.
