# MTProxy Pushok v1.15

В ответе `/start` убрано старое сообщение о разработке. Пушок приветствует пользователя, объясняет назначение кабинета и показывает ссылку подключения к локальному MTProxy. В меню появилась кнопка **«Подключить прокси»**.

Ссылка формируется из `/etc/mtproxy-pushok/mtproxy.env`: текущие адрес, порт и клиентский secret. Административные токены, рекламный тег и сам файл конфигурации боту не передаются. В GitHub параметры установленного сервера не сохраняются.

На стандартной установке ссылка подготавливается при обновлении и затем обновляется локальным агентом каждые 20 секунд. Бот перечитывает её при ответе, без перезапуска. Если конфигурация удалена или неверна, старая ссылка снимается. Поддерживается классический MTProxy этого установщика, с обычным или `dd`-секретом. Для отдельно установленного удалённого/Docker-прокси автоматическая ссылка не создаётся.

Обновление: **Профиль → Версия и обновления → Установить обновление**. После установки отправьте боту `/start`: сохранённое приветствие обновится, меню появится внизу чата. Массовой рассылки нет. Приветствие профиля, задаваемое через Telegram, этот выпуск не изменяет.

Проверены сборка ссылки из конфигурации, смена адресных параметров и секрета, отправка приветствия с кнопкой, удаление устаревшей ссылки и отклонение некорректных файлов. Это проверка кода; фактическое подключение к конкретному VPS проверяется в Telegram.
