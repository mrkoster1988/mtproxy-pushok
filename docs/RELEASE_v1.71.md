# v1.71 — Единый интерфейс кабинета

- Единые компактные карточки пользователей, цвета никнеймов по роли, роли без рамок и карандаша, спокойная точка онлайн.
- Лидеры месяца в отдельном блоке на главной; уменьшенный квадратный пьедестал с бегущей световой волной.
- Личные сведения показаны короткими строками; сохранённая дата скрыта от редактирования, инструменты владельца раскрываются отдельно.
- Список приглашённых сохраняет страницу и уже загруженных людей при ошибках; повтор и переходы не пропускают участников.
- Кнопка добавления справа от поиска каналов и кампаний; единые иконки действий с доступными названиями.
- Поиск тематики внутри Mini App, сгруппированные сворачиваемые настройки и доступная настройка реферальной награды.
- Последние пять обновлений доступны в профиле; полный журнал открывается по ссылке.

Реферальная награда настраивается в Настройки → Система → Пользователи и награды → Приглашения и награды. Купон выдаётся после первого реального рублёвого оплаченного и завершённого размещения. Изменение условий действует на новые приглашения; уже принятые сохраняют условия.

Изменения затрагивают интерфейс. Новая миграция БД не требуется. Волна отключается при системном уменьшении анимации.
