# Pushok 2.34

В профиле можно разрешить боту уведомления. В своей карточке VPN откройте «Моя подписка в Telegram».

В поддержке обращения открываются отдельными темами. Из раздела диагностики Flow 2.0.8 можно передать проверку DNS и HTTPS с телефона.

Разработчику доступен редактор в настройках Pushok ИИ. Выберите продукт, язык и иллюстрацию, затем подтвердите вариант и канал. Для генерации ключу ИИ требуется возможность «Посты и иллюстрации о Pushok». Для отправки добавьте бота кабинета в канал с правом публикации.
