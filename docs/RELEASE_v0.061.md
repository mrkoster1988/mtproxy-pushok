# v0.061: дизайн Mini App и мобильная навигация

Выбранный дизайн подключён к существующему кабинету: главная с карандашным
Пушком, карточки кампаний и каналов, оплаты, профиль и нижняя навигация.
Модерация, оплата и размещение показаны отдельно. Заголовок кампании в очереди
спонсоров открывает операторскую карточку, в том числе для чужих рекламных заявок.
Баланс и бонусы не имитируются: главная показывает реальные статусы оплат.

Схема базы, тарифы и платёжные настройки этим выпуском не меняются. Сумма Stars
берётся из API, результат оплаты подтверждает сервер. СБП остаётся во внешнем
кабинете. Браузерная проверка использует изолированную PostgreSQL и тестовые
Telegram SDK и платёжный транспорт; она не проводит реальные платежи.

## Установка через существующий обновлятор

1. После публикации `release/stable` откройте раздел обновлений в настройках
   администратора и запустите обновление. Настроенное владельцем расписание
   также может поставить его в очередь. Слияние PR само по себе не подтверждает
   установку на VPS.
2. Обновлятор проверяет отсутствие локальных изменений и возможность fast-forward,
   создаёт полную закрытую резервную копию, затем собирает и перезапускает сервисы.
   Копирование может временно остановить кабинет. Дождитесь успешного результата;
   повторные нажатия не заменяют проверку состояния.
3. Проверьте версию API `0.061` и SHA установленного коммита в разделе обновлений.
   Закройте и заново откройте Mini App в Telegram, чтобы загрузить новый интерфейс.
4. Проверьте вход, открытие своих кампаний, меню и возврат, создание заявки,
   отображение трёх статусов. Оператор должен открывать кампанию из очереди
   спонсоров по заголовку и по кнопке управления.

Если обновление завершилось ошибкой, сохраните показанные этап и код ошибки.
Не удаляйте Docker-тома и не восстанавливайте БД поверх текущих заказов.
Порядок восстановления: [INSTALL_RECOVERY.md](INSTALL_RECOVERY.md), состав полной
копии и пробное восстановление: [CABINET_BACKUP.md](CABINET_BACKUP.md).
Для проблемы с удалённым образом старой версии см. [v0.060](RELEASE_v0.060.md).

## Что проверяется на установленной системе

Telegram safe area, клавиатура, настоящий вход и оплата проверяются в приложении
на своей конфигурации. Отдельно проверяются назначение подготовленного тега,
фактический показ спонсорского канала и его снятие после окончания или отмены.
Новый дизайн не меняет механизм показа; наличие статуса оплаты или назначенного
слота не доказывает, что Telegram уже показывает спонсора.
