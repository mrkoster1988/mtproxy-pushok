# v1.44 — пользователи

Карточки пользователей уплотнены: уменьшены фото, шрифты и отступы. Роль расположена справа сверху; администраторы выделены красным, операторы зелёным. Время последнего входа находится в нижней строке. Редактор прав раскрывается на полную ширину карточки, цвет роли обновляется после сохранения.
