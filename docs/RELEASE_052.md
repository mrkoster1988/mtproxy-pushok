# v0.052 — цветные кнопки бота

Обновление: **Настройки → Система → Установить обновление**. Дождитесь успешного
завершения, затем отправьте боту `/start` или откройте раздел меню.
Если служба обновлений ещё не установлена, выполните однократную команду
из [инструкции v0.051](RELEASE_051.md).

| Цвет | Действия |
| --- | --- |
| Зелёный | Разместить рекламу, создать черновик, отправить заявку, оплатить Stars, одобрить |
| Синий | Mini App, кампании, тарифы, канал, главное меню, очередь модерации, диагностика |
| Красный | Отмена, отказ в модерации |
| Обычный | Помощь и неизвестные действия |

Используются нативные `style: success/primary/danger` из
[Telegram Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton).
Точный оттенок зависит от Telegram. Цвет не заменяет подпись и значок кнопки.
PushokIcons сохраняются; при отказе Telegram по custom emoji повторное меню
сохраняет цвет и обычный текстовый значок.

Цвета применяются при отправке и редактировании меню. Ранее отправленные карточки
кампаний и оплаты массово не редактируются. Ссылки, callback и платёжные запросы
остаются прежними. Обновление не меняет настройки включения Stars/СБП и цены тарифов.
