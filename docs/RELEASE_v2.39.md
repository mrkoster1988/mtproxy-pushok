# Профиль, кампании и баланс

Из пользовательского профиля убран блок «Личные сведения». Карточка подписки и значок верификации остаются в профиле. Скачивание Pushok Flow для Android и тарифы доступны во вкладке VPN. Под кнопкой оплаты сначала показано согласие, ниже находятся свёрнутые условия.

В пользовательском списке кампаний кнопка «Продвигать канал» расположена после списка. Поиск и фильтр доступны сотрудникам.

На странице баланса кнопки «Пополнить» и «Мои оплаты» одинакового размера. Активация кода находится в начале списка «Мой кошелёк».
