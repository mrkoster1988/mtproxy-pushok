# v1.57 — Автоматическая проверка публичного канала

При вводе ссылки или @username форма сама проверяет канал через 600 мс после последнего изменения. Лупа остаётся для повторной проверки. Появляются название, логотип при наличии фотографии и результат проверки. Название, введённое вручную, не заменяется. Выбор сохранённого канала также запускает проверку.

Группы и личные аккаунты не принимаются. Для закрытой/несуществующей ссылки показывается сообщение о недоступности публичного канала. Сетевые ошибки, ограничение частоты и ошибки конфигурации Telegram не выдаются за закрытый канал. Проверка ограничена по времени; после ошибки можно исправить ссылку или повторить запрос.

Сервер независимо проверяет добавление и изменение канала, отправку общей формы и повторную отправку исправленной заявки. Только успешный предпросмотр кэшируется на 30 секунд, с разделением по токену и среде Telegram. При записи и отправке выполняется свежий запрос, без использования этого кэша. Проверка прав остаётся отдельной: публичность не означает владение каналом.

Сетевой запрос выполняется без удержания блокировок БД. После него сервер проверяет, что ссылка и ранее подтверждённый Telegram ID не изменились. При отказе не создаётся заявка или запись об успешной отправке. Повтор с уже сохранённым ключом возвращает прежнюю заявку даже при недоступном Telegram.

Существующая проверка типа, username и идентификатора канала перед автоматической привязкой в MTProxyBot сохраняется. Публичность не гарантирует доступность прокси, успешную привязку или фактический показ рекламы. Счета и подтверждение уже совершённых платежей этим обновлением не изменяются.

## Установка

Профиль → Версия и обновления → установить v1.57. После обновления закрыть и снова открыть Mini App. Дополнительная настройка проверки не требуется; используется уже настроенный токен бота.

## Проверки

Тесты покрывают публичные и дополнительные username, группы/личные чаты, неверные ссылки, ошибки и тайм-аут Telegram, изоляцию сред, кэш, права доступа, откат, гонку изменения ссылки и безопасный повтор отправки. Chromium проверяет автозапуск, заполнение названия, сохранение ручного названия, сообщения об ошибках, поздние ответы, тайм-аут и ширину 320 px.

Telegram и платежи в проверках заменены тестовыми ответами; API и PostgreSQL работают локально. Проверка на живом VPS выполняется после установки.
