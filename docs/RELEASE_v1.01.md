# MTProxy Pushok v1.01

## Где обновлять

Откройте **Профиль** в нижнем меню. Сразу под заголовком находится **Версия и обновления**. Администратор видит:

- «Установлено» — версия работающего API, а не номер из журнала старой установки;
- «Опубликовано» — версия из `release/stable`;
- время последней успешной проверки, отдельно — результат последней установки;
- «Проверить», «Установить v…» и «Что изменилось».

Если опубликована новая версия, сверху кабинета появляется уведомление. В **Настройки → Система** также есть ссылка на блок обновлений. Рекламодателям и операторам управление обновлениями не показывается.

Проверка выполняется при входе администратора, при возврате в открытую вкладку и каждые пять минут, пока кабинет видим. Кнопка проверки использует общий серверный кеш до 60 секунд. Уведомления приходят внутри кабинета; сообщения Telegram и проверки при закрытом кабинете в этот выпуск не входят.

При недоступности GitHub прежние данные помечаются «ранее», актуальность не подтверждается и установка недоступна до успешной проверки. Если запущенная версия новее опубликованной, автоматический откат не предлагается.

Установка запускается только по кнопке. Существующий обновлятор создаёт резервную копию, получает `release/stable`, собирает приложение и проверяет запуск. Миграций БД в выпуске нет, агент и параметры MTProxy не меняются.

## Нумерация

`v1.00` — крупный этап; `v1.01`, `v1.02` и далее — доработки. Следующий крупный этап — `v2.00`. Сравниваются целые части версии: `v1.10` новее `v1.09`. Старые версии `v0.066` и ранее остаются в истории. Первый выпуск новой схемы — **v1.01**; отдельный выпуск v1.00 задним числом не создаётся.

## Проверка

Автотесты покрывают сравнение старой и новой нумерации, отказ GitHub, кеш, метаданные конкретного коммита, роли API и отсутствие секретов в запросах. Браузерный сценарий с изолированными метаданными проверяет актуальную и новую версии, ошибку связи, очередь установки, повтор после ошибки и ширины 320/390 px. Работа обновлятора на VPS подтверждается отдельно после установки владельцем.
