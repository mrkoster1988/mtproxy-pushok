# v0.058 — компактный кабинет и автоматический подбор слотов

- Плоское меню; административные разделы выделены, закрытие крестиком.
- Компактные кнопки, статусы и даты; таблицы на телефоне превращаются в карточки.
- Уведомления скрываются через пять секунд и закрываются вручную.
- Экран готовности запрашивает публичный результат GitHub CI установленного обновлятором коммита; показывает SHA и дату. При недоступности GitHub результат не выдумывается.
- CSV убран из интерфейса; история и API отчётов сохранены.
- Бот использует один стиль: полный набор фирменных иконок или обычные эмодзи.
- Архивирование заявок разрешено при оплатах и будущих слотах. Платежи и аудит сохраняются; будущий слот отменяется, активный показ остаётся под контролем оператора.
- Канал можно убрать из своего списка. Новые заявки на архивный канал запрещены.
- Фоновый sbp-worker независимо от включения СБП назначает свободный период одобренным оплаченным/бесплатным заявкам. Интервал проверки — минута; горизонт — 90 дней. Учитываются другие кампании и живые брони. Двойное назначение блокируется транзакциями.
- Ручное снятие слота приостанавливает автоподбор; оператор может включить его снова.

Обновление: Настройки → Система → Установить обновление. Применяется миграция 026; worker должен быть запущен. При отсутствии узлов заявка остаётся в ожидании.

Назначение слота не включает спонсорский тег и не подтверждает показ. Реальное переключение тега и проверка Telegram остаются отдельным этапом. При архивировании узла будущие размещения возвращаются на подбор; активные показы сохраняются у оператора. Платёжная история не удаляется.
