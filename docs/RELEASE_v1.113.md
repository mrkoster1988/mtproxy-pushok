# v1.113 — Экран обновления кабинета

При установке открывается экран «Идёт обновление» с шагающим Пушком и полосой фактических этапов.

Caddy из установщика показывает экран даже во время перезапуска API. Кабинет открывается автоматически после восстановления.

Для уже работающей установки экран доступен после первого обновления до этой версии. Если у кабинета свой reverse proxy, используйте [настройку экрана для своего прокси](INSTALL_QUICKSTART.md#экран-обновления-на-своём-reverse-proxy).

Главная компактнее. Блок подключения квадратный, подтверждение номера раскрывается по нажатию. Никнеймы пользователей видны администраторам и модераторам.
