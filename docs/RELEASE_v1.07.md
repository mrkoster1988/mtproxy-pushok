# MTProxy Pushok v1.07

- Уведомления администраторов и операторов о кампаниях из Mini App и бота: канал, рекламодатель, переход к заявке.
- Новые уведомления отправляются отдельным сообщением; ошибки доставки повторяются через очередь.
- В карточке модерации показаны имя, @username и Telegram ID рекламодателя.
- На экране загрузки — утверждённый Пушок с анимацией дыхания и хвоста.
- Надпись экрана загрузки настраивается в «Настройки → Система».
- Аватар пользователя Telegram в профиле Mini App.

## После установки

Для получения уведомлений отправьте /moderation в личный чат @mtproxy_pushok_bot с аккаунта администратора или оператора.
Обновление применяет миграцию 029 для очереди модерации. Полностью закройте и заново откройте Mini App.
Установка на VPS и доставка реального уведомления требуют отдельной проверки.
