# v1.83 — Единые элементы кабинета и профиль ИИ

Кнопки форм располагаются справа от связанных полей. Справка открывается по i в строке заголовка. Списки выбора используют оформление puShok, клавиатуру и поиск для длинных списков; исходные поля сохраняют значения, обработчики, обязательность и отправку формы.

Сверка пополнений загружается при раскрытии раздела. Лишняя кнопка перед списком удалена, реквизиты платежа открыты. Журнал операций показывает сумму и дату компактными строками. Карточка рекламодателя использует общий компонент, полномочия выровнены по нижней строке сведений.

В модерации: «Одобрено: Агент ИИ», ссылка на служебный профиль и открытый сохранённый разбор. Новый анализ запускается явно. Ссылки на настройки из этих блоков убраны. История и документы открывают компактный отчёт, хронологию, статистику и выгрузку без повторной карточки статусов.

Миграция 059 создаёт служебный аккаунт без Telegram ID и возможности входа. Профиль доступен сотрудникам. Одобрения, передачи сотруднику, повторы и отклонения считаются по журналу решений; автоматический отказ сейчас выключен. Счётчики относятся к решениям, отдельный счётчик — к уникальным кампаниям. Тема фиксируется при новых решениях; у старых записей отображается «Тема не сохранена». Ручное решение после ИИ не приписывается агенту. Финансовые данные не изменяются.

Проверки: серверные тесты с PostgreSQL; сценарии реальных форм, выбора мышью и клавиатурой, платежей, прав доступа и мобильной геометрии. Для установки используйте «Версия и обновления», затем переоткройте Mini App.
