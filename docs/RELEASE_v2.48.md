# v2.48 — Аккуратные статусы пользователей

- Статусы отображаются текстом через среднюю точку, без иконок.
- Одиночная роль остаётся справа; сочетание ролей переносится на отдельную строку карточки и сохраняет цвета.
- Добавлены браузерные проверки каталога и профиля на ширине 320, 390 и 768 пикселей.

Изменение только отображения. Основные роли, дополнительные статусы, права, данные и подписки не меняются. Новая миграция не требуется.
