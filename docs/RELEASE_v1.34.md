# v1.34 — пользователи, никнеймы и управление бонусами

**Профиль → Пользователи** открывает администратору полный каталог аккаунтов:
поиск по @username (без учёта регистра), имени, Telegram ID или внутреннему ID;
фильтры роли и входа в приложение, страницы по 20 пользователей. Карточка
открывает профиль с каналами, кампаниями и балансом. Рубли, бонусы и старый
внутренний XTR видит только администратор; оператору эти данные не передаются.
«Управлять балансом» сразу выбирает нужный аккаунт.

Последний вход фиксируется при создании сессии и сохраняется при отзыве сессий.
Миграция восстанавливает доступные сведения из существующих сессий; если сессии
были удалены раньше, дата появится после следующего входа.

В разделе «Кампании» администратор и оператор по умолчанию видят все текущие
заявки. Переключатель «Мои кампании» показывает только личные. Поиск также
понимает никнейм рекламодателя. Из карточки открывается управление заявкой.

Для назначения роли, подарочного кода и персонального предложения работает
единый выбор пользователя по никнейму. При нескольких совпадениях нужно выбрать
конкретный аккаунт. Поиск охватывает пользователей, уже известных кабинету;
поиск произвольных аккаунтов Telegram не выполняется. До первого входа
персональный подарок можно адресовать точному Telegram ID.

У бонусов одинаковые кнопки со значками: поделиться, скопировать, изменить,
удалить, включить/выключить; у подарочных кодов — история активаций. Удаление
останавливает новые применения, сохраняет историю и доступно для отмены
через вкладку удалённых. Восстановленные предложения остаются выключенными.

После первой активации подарка нельзя менять сумму и получателя; лимит нельзя
опустить ниже числа активаций. У использованного промокода сохраняются код и
получатель, а изменения условий касаются будущих заявок. Уже зафиксированная
цена заявки и прошлые начисления не пересчитываются. У заработанного
реферального купона редактируются только название и срок; отключённая награда
не включается повторно. Все изменения записываются в аудит.

Миграция **043_users_bonus_management.sql** добавляет время входа и мягкое
удаление. Установщик и обновление применяют её автоматически. Возможности
автоматического расписания из v1.33 сохраняются.

Проверки: реальные PostgreSQL/API, доступ по ролям, сохранение проводок и цен,
повторные активации, выбор получателя по никнейму, создание/изменение/удаление
в Chromium и отсутствие горизонтального переполнения на ширинах 320 и 390 px.

Обновление: **Профиль → Версия и обновления → Установить v1.34**.
Публикация в GitHub сама по себе не устанавливает версию на VPS.
