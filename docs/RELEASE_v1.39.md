# v1.39 — компактные карточки каналов

В «Моих каналах» логотип и название стоят рядом с тремя небольшими иконками: изменить, отчёт, удалить. Под разделителем расположены количество текущих кампаний и кнопка создания заявки. Панель действий больше не занимает отдельную пустую строку. Длинные названия занимают максимум две строки, @username сокращается при нехватке места; полный текст сохраняется в карточке и редакторе.

Поиск получил значок, подсветку активного поля и кнопку очистки. Кнопка «+» открывает отдельный экран добавления по маршруту `#/channels/new`. В нём можно найти название и логотип по ссылке или @username, заполнить название вручную, отменить ввод или вернуться назад. После успешного добавления снова открывается список. Незавершённый ввод сохраняется при возврате; после успешного сохранения форма очищается. Повторная отправка уже добавленного канала показывает ошибку, как раньше.

Проверки: Chromium с настоящими FastAPI/PostgreSQL — поиск и очистка, добавление/отмена/назад, выбор нужного канала при создании кампании, отсутствие наложений на 320/390/768 px, редактирование, отчёт и удаление. Telegram отвечает тестовыми данными; внешние сообщения не отправляются. Для обновления работающего Mini App нужно установить версию на VPS и открыть приложение заново.
