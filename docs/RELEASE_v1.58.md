# v1.58 — Компактный профиль и приглашённые

«Личные сведения» в собственном профиле свёрнуты по умолчанию. Нажатие на заголовок открывает телефон и компактную форму даты рождения. Для подтверждённого номера показаны синяя фигурная галочка и зелёное «Верифицирован». Сохранение даты и согласия на поздравления работает как прежде.

В карточке пользователя и собственном профиле появилась строка «Приглашено» с количеством зарегистрированных по реферальной ссылке пользователей. Число не зависит от оплаты или выдачи награды. В карточке пользователя оно остаётся видимым при свёрнутых сведениях об аккаунте. Права доступа сохранены.

## Установка

Профиль → Версия и обновления → Проверить → Установить v1.58. Проверка доступной версии кэшируется на 60 секунд. После успешного обновления закрыть и снова открыть Mini App.

Выпуск содержит изменения v1.57, включая автоматическую проверку публичности канала. Дополнительная настройка и новая миграция для этих изменений профиля не требуются.

## Проверка

Открыть собственный профиль, раскрыть «Личные сведения», проверить сохранение даты рождения. В карточке пользователя проверить число приглашённых; при отсутствии приглашений отображается 0. Номер установленной версии после успешной установки должен быть 1.58.

API/SQL и браузерные проверки профиля пройдены на тестовых данных. Установка на рабочий VPS проверяется отдельно.
