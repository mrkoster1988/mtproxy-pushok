# v1.98 — Сроки запуска, оплата бонусами и сортировка пользователей

В карточках кампаний видны запланированное время запуска или условие для назначения свободного периода. Время указано по Москве.

У статистики ссылки появился единый блок с кнопками подключения и отчёта.

Администратор может разрешить или выключить оплату бонусными рублями в веб-кабинете.

В каталоге пользователей доступна сортировка по имени, регистрации и последнему входу.

Настройка находится в «Управление → Платежи → Внутренний баланс». Для существующих установок оплата бонусами включена. Переключатель распространяется на ручную оплату и автосписание. Возврат сохраняет исходное распределение рублей и бонусов. В Telegram действует оплата Stars.
