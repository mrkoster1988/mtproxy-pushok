# v0.066: подтверждение показа в своём Telegram

Форма требовала второй аккаунт даже при наблюдаемом показе на основном.
Теперь можно использовать свой аккаунт: он должен быть подключён к прокси
кампании, не подписан на канал и видеть отметку «Спонсор прокси».

Путь: Mini App → ☰ → Узлы → Очередь размещений → Управлять размещением →
Подтвердите фактический показ. Запишите свежее наблюдение, при желании приложите
скриншот, подтвердите условия и нажмите «Подтвердить показ и активировать».

Проверки оплаты, назначенного периода и свежести наблюдения сохранены.
API и схема БД не меняются. Метод `separate_unsubscribed_client` сохранён для
совместимости и обозначает проверку в Telegram отдельно от рекламного кабинета.
Существующие наблюдения и кампании не переписываются.

Активная карточка показывает состояние применения тега и поясняет завершение.
При автоприменении агент возвращает исходный тег по окончании срока. Если
исходный тег соответствует тому же каналу, канал может остаться спонсором:
это не доказательство сбоя возврата и не подтверждение прекращения показа.
«Подтвердить завершение» по-прежнему требует проверки снятия тега и отсутствия
канала кампании среди спонсоров; обновление не завершает кампании автоматически.

Проверены формы, сохранение наблюдения и активация в браузере с отдельной БД;
пропуск обязательного подтверждения не отправляет форму. Код возврата тега
не менялся: его тесты покрывают окончание срока, недоступность API и сбой
восстановления. Живое завершение и переключение на VPS проверяются отдельно.

После публикации release/stable обновление доступно в «Настройки → Система →
Установить обновление». Ожидаемая версия — 0.066. Инструкция и подтверждённое
наблюдение показа: [MTProxy_SPONSOR.md](MTProxy_SPONSOR.md).
