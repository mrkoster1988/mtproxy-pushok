# v1.124 — Упрощение подписки и доступ к сведениям кампаний

- На главной странице удалена ссылка «Как работает реклама».
- После успешной проверки подписки обе кнопки подписки скрываются, остаётся сообщение о подтверждении и доступная кнопка подключения.
- Кнопки «Подписаться на канал» и «Проверить подписку» теперь имеют одинаковый стиль.
- Детали рекламных кампаний доступны владельцу только по своим заявкам. Операторы, модераторы, администраторы и разработчики имеют доступ к защищённым операторским сведениям. Общего списка подписчиков API не предоставляет.
