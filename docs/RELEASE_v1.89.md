# v1.89 — Закрытый репозиторий и установка

Установщик и проверка версий поддерживают приватный GitHub. Режим `bash setup.sh --repository-access` принимает токен скрыто, проверяет чтение Contents и Actions и сохраняет доступ на VPS с правами 0600. Git helper ограничен одним репозиторием; токен не включается в аргументы команд, remote URL, Git config или Docker build context. Заголовок API-авторизации не переносится при HTTP-перенаправлении.

Служба обновления не зависает на интерактивном запросе пароля. Ошибка доступа останавливает обновление до резервной копии, смены исходников и миграций. Новая установка получает опубликованную ветку `release/stable`. Для старого VPS предусмотрен переход с интерактивным скачиванием и последующей настройкой токена.

README переработан вокруг чистого трафика, прозрачного учёта и ИИ: проверка каналов, определение тематики, разбор решений, профиль и статистика агента. Указаны границы измерения аудитории и модерации, без обещаний гарантированного числа подписчиков или отсутствия всех ботов.

Проверки включают реальные вызовы локального Git credential helper с искусственным токеном, ограничение адресата, права файлов, отказ от symlink, сохранение прежнего токена при ошибке, API-запросы с авторизацией и отсутствие пересылки секрета при redirect. Токены реального владельца в тестах не используются.

Видимость репозитория меняется отдельно в GitHub; эта версия лишь подготавливает установку к закрытому доступу. Смена видимости не скрывает код от администратора VPS и не удаляет ранее скачанные копии. Лицензии сторонних компонентов сохранены.
