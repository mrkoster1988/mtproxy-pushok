# v2.45 — Тамада — управление мероприятиями

- Независимый статус «Тамада» сочетается с модератором и другими ролями.
- Тамада управляет всеми мероприятиями, организаторами, лимитами, подарками и архивом.
- Администратор и разработчик назначают статус в карточке пользователя; остальные права не расширяются.

Новая миграция 094 сохраняет существующие роли и подарки. Архив не отменяет действующие подарочные ссылки. Подробности: [Тамада](TAMADA_EVENTS.md).
