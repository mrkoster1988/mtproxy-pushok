# v1.93 — решение модератора из очереди

В Mini App откройте **Модерация** под учётной записью администратора или оператора. У заявки со статусом **У модератора** справа от даты видны две кнопки. Зелёная галочка одобряет заявку. Красный крестик открывает поле для причины отказа. Введите причину для рекламодателя и подтвердите отказ или нажмите «Отмена», чтобы оставить заявку на проверке. После сохранения решения кнопки исчезают.

В **Главная → Ваши кампании** рекламодатель видит причину и время последней проверки. При временном сбое отображается ожидание повтора. Если публичных текстов недостаточно для одобрения, заявку получает сотрудник. Для заявок в объявленной категории «18+ · Для взрослых» агент указывает эту категорию в основании отказа. Очередь модерации обрабатывается отдельно от сверки СБП.

При автопривязке спонсора агент понимает оба ответа Telegram на команду `/myproxies` — список и сразу открытую карточку. Перед назначением он сверяет узел и тег. Состояние привязки видно в **Узлы и спонсоры → Автоприменение**.

## Обновление с v1.92

В кабинете администратора откройте **Версия и обновления** и проверьте доступную версию. Для штатного обновления выберите **v1.93**. После обновления переоткройте Mini App. Новых миграций БД в этом выпуске нет.

Если на VPS применялись отдельные исправления из чата, выполните `git -C /opt/mtproxy-pushok status --short`. Штатный обновлятор останавливается при локальных изменениях в отслеживаемых файлах. Порядок подготовки рабочей копии и резервного копирования описан в [инструкции обновления](INSTALL_QUICKSTART.md). Сохраните свои правки перед обновлением.

Для ранее выданных исправлений v1.92 можно проверить, что они целиком вошли в стабильный выпуск. Следующий блок рассчитан на Git в Ubuntu 24.04. Он проверяет отслеживаемые файлы и подготовленные к коммиту изменения, оставляет резервную копию известных правок в Git stash и останавливается, если в рабочей копии есть отличия, требующие разбора. Выполняйте из SSH перед нажатием кнопки установки.

```bash
(
set -eu
cd /opt/mtproxy-pushok
git fetch --no-tags https://github.com/mrkoster1988/mtproxy-pushok.git refs/heads/release/stable
set -o pipefail
git show FETCH_HEAD:scripts/prepare_v193_update.py | python3 -
)
```
