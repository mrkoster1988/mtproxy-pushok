# v2.47 — Мероприятия — проверка сессий и получение подарков

- Отозванная сессия не может создавать, редактировать или получать подарки по ранее начатому запросу.
- При получении подарка отображается фактическая причина отказа Shop, а не ошибка изменения тарифа.
- Оформляемые подарки помечаются отдельно; повторная проверка использует тот же подарок.
- Некорректные и перенаправленные ответы Shop не принимаются за успешные.

Новая миграция не требуется. Неопределённый ответ Shop не освобождает подарок для другого получателя: это сохраняет защиту от двойного начисления.
