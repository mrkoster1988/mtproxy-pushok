# Pushok Custom Emoji — подключение к Telegram Bot API

## Статус
Поддержка параметра `icon_custom_emoji_id` добавлена **с безопасным отключением по умолчанию**. Это ещё не означает, что emoji опубликованы в Telegram или проверены с настоящим ботом. Нативные кнопки Telegram не принимают SVG из веб-ассетов.

Первоисточник: https://core.telegram.org/bots/api#inlinekeyboardbutton и https://core.telegram.org/bots/api#keyboardbutton.

## Как включать после регистрации своего набора
1. Подготовить Telegram Custom Emoji из оригинальных Pushok Icons по требованиям Telegram (обычно через @Stickers).
2. Убедиться, что у бота есть право использовать custom emoji на кнопках: дополнительные имена через Fragment **либо** владелец с действующим Premium для допустимых сообщений. Отдельно проверить на целевой версии Telegram.
3. Получить фактические числовые `custom_emoji_id` опубликованных значков. Не использовать ID других наборов без разрешения и не выдумывать их.
4. Составить JSON-соответствие команд и ID. Пример ниже — **плейсхолдеры и не включаются в работу**.
5. В конфигурации процесса бота установить `PUSHOK_BUTTON_ICONS_ENABLED=1` и `PUSHOK_BUTTON_EMOJI_JSON` с реальными ID.
6. Перезапустить только бота и проверить приватные/групповые сообщения, inline- и reply-кнопки на клиентах Telegram. При ошибках — установить `PUSHOK_BUTTON_ICONS_ENABLED=0` и проверить, что обычное меню сохранилось.

## Гарантии обратной совместимости
- По умолчанию иконки выключены, старые тексты, callback, URL, права, токены и бизнес-операции не меняются.
- Некорректный/пустой JSON и ID не попадают в ответ Telegram.
- Лишние ключи настроек игнорируются.
- Отсутствующие ID не скрывают кнопки; текст остаётся видимым.
- Ни одна иконка не означает успешную оплату/активацию без серверного подтверждения.

## Настройка
Параметры:
- `PUSHOK_BUTTON_ICONS_ENABLED=0` — выключено (по умолчанию).
- `PUSHOK_BUTTON_EMOJI_JSON='{"buy":"<реальный_числовой_ID>"}'` — карта действий; заменяйте пример настоящими ID после публикации набора.

Не храните токены ботов или личные данные в JSON-карте; это лишь публичные числовые ID эмодзи.
