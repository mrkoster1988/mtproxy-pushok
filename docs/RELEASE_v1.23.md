# v1.23 — подключение СБП из кабинета

Профиль → Настройки → Платежи → Подключение СБП · ЮKassa. Введите Shop ID, секретный ключ, домен возврата без протокола и выберите тестовый или рабочий магазин. Кнопка «Проверить и сохранить» обращается к GET /v3/me, сверяет магазин, режим, статус и доступность СБП. Счёт при проверке не создаётся. После сохранения включите «Принимать СБП» и сохраните способы оплаты.

Shop ID находится в ЮKassa → Настройки → Магазин; ключ — Интеграция → Ключи API. Пустое поле ключа сохраняет ранее заданный ключ. Сам ключ никогда не возвращается в ответах API. Конфигурация хранится в приватном файле .control/sbp-private.json с правами 0600; API и worker используют её сразу, без перезапуска. Архивы с .control содержат секреты и должны храниться приватно. До сохранения используются прежние переменные окружения.

При наличии СБП-счетов магазин, домен и режим не меняются через эту форму: это требует отдельного переноса и сверки. Ключ того же магазина можно заменить после проверки. Неудачная проверка сохраняет прежнюю конфигурацию. Подключение доступно только администратору и записывается в аудит без ключа.

Проверка API не подтверждает реальное зачисление денег. СБП для цифровых размещений используется внешним веб-кабинетом; существующие ограничения Telegram Mini App сохраняются. Банк, магазин ЮKassa, фискализация и разрешение СБП оформляются отдельно в ЮKassa.
