# v1.45 — кампании

В списке кампаний канал и прямой переход в Telegram находятся рядом с текущим статусом. Тариф, срок и стоимость сгруппированы в три колонки; сохраняются отдельные состояния модерации, оплаты и размещения. На подробном экране добавлена линейка шести этапов, вычисляемая по серверным статусам. Даты и стоимость используют данные заявки; примерные охваты, переходы и конверсии не подставляются.
