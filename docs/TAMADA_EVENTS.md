# Тамада — независимый статус

Назначение и снятие: администратор или разработчик, каталог пользователей, карточка прав. Статус не заменяет роль; модератор сохраняет модерацию, отметка «Друзья» не меняется. Новый статус по умолчанию выключен.

Тамада видит все мероприятия, создаёт мероприятия, назначает организаторов, меняет лимиты (не ниже числа неотозванных подарков), оформляет карточки, выпускает и отзывает подарки, видит получателей и архивирует/восстанавливает мероприятия. Архив запрещает новые подарки и отправку карточек; уже выданные ссылки действуют, пока не отозваны. Снятие статуса не отнимает права назначенного организатора на собственные мероприятия. Права администрирования, финансов и назначения ролей не расширяются. Изменение статуса журналируется; проверка доступа выполняется на API.

Миграция 094 добавляет независимые поля без изменения существующих данных. После применения миграции пользователь может заново открыть Mini App, чтобы обновить интерфейс.
