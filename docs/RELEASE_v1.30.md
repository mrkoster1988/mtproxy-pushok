# v1.30 — скидка после смены тарифа клиентом

Исправлен пересчёт индивидуальной скидки, когда рекламодатель выбирает
другой тариф в черновике или возвращённой заявке после правки администратором.
Раньше могла сохраниться исходная цена Stars предыдущего тарифа: для нового
тарифа 451 Stars скидка 10% могла дать 136 Stars вместо 406 Stars.

Теперь смена тарифа обновляет обе исходные цены и снимает прежнюю
индивидуальную скидку, её название и процент. Следующая скидка рассчитывается
от нового тарифа. Изменение только даты или выбор прежнего тарифа сохраняет
индивидуальные условия. Последующие правки каталога не меняют уже сохранённую
цену заявки; отсутствие цены Stars также сохраняется.

Регрессионные проверки охватывают черновик, отзыв с модерации, возврат на
доработку, скидки 0/20/100%, повторную скидку с тем же процентом, устаревшую
форму администратора, обе точки API и сумму счёта Stars после модерации.

Миграция базы данных не требуется. Уже созданные заявки и счета автоматически
не пересчитываются. Для неоплаченной заявки с неверной ценой администратор
может выбрать другой тариф, вернуть нужный и назначить согласованную скидку;
открытый счёт и оплаченная заявка остаются защищены от изменения.

Установка: **Профиль → Версия и обновления → Установить v1.30**.
Публикация в GitHub не означает установку на VPS.
