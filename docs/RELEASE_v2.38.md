# Подписка и тарифы VPN

Во вкладке VPN и личном профиле карточка подписки пользователя раскрыта при входе. Под ней расположена зелёная кнопка «Скачать Pushok Flow» для Android.

Выберите тариф по названию, сроку и цене. Под карточками находится кнопка «Оплатить» с выбранной суммой. Ниже раскройте «Условия оплаты» и поставьте отметку согласия. Если сразу нажать «Оплатить», условия откроются автоматически. После подтверждения нажмите кнопку оплаты, чтобы открыть счёт.
