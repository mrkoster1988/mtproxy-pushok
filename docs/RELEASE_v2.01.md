# MTProxy Pushok v2.01

К существующему аккаунту MTProxy можно привязать ключ доступа и входить в том же браузерном кабинете для Flow и Shop с помощью PIN-кода или биометрии устройства.

Откройте кабинет тем же аккаунтом и выберите «Вход без Telegram» → «Добавить ключ входа». При следующем входе нажмите «Войти ключом доступа». Подписки и баланс привязаны к прежнему аккаунту. При смене устройства потребуется доступ к сохранённому ключу или исходному способу входа.
