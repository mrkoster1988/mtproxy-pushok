# v1.112 — Разработчики и личные ссылки

Приглашение к прокси и QR-код используют HTTPS-адрес открытого кабинета. В установщике указывается действующий домен.

Только администраторы и модераторы могут перейти в Telegram пользователя. Для остальных ник в профилях, списках приглашённых и рейтингах отображается текстом.

Разработчик может назначать и снимать роль «Разработчик» у других участников. Смена прав завершает прежние сеансы пользователя.
