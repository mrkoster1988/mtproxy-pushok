# MTProxy Pushok v1.129

На совместной установке с Shop v0.068 кнопка входа в магазине открывает кабинет MTProxy. Войдите через Telegram, проверьте отображаемый аккаунт и нажмите «Продолжить в магазин». Магазин создаёт часовой пользовательский сеанс в исходном браузере.

Для сопряжения используется настроенный серверный ключ Flow–Shop. Браузерное подтверждение привязано к одноразовому запросу магазина. Вход через Android Flow продолжает использовать своё подтверждение.
