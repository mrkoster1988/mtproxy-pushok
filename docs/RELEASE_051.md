# v0.051 — исправления первого запуска

## Уже работающая установка v0.050

Старая кнопка «Обновить» перечитывает данные. Для установки ПО нужен host-worker;
однократно установите новую версию и службу (root, /opt/mtproxy-pushok):

```bash
cd /opt/mtproxy-pushok && git fetch origin release/stable && git merge --ff-only FETCH_HEAD && bash scripts/install_updater.sh
```

Затем закройте Mini App и откройте снова. Настройки → Система → «Установить обновление».
Служба получает только фиксированную ветку release/stable из официального репозитория,
отказывается от изменения отслеживаемых локальных файлов, делает приватную копию
базы/чеков/конфигурации, собирает образы, выполняет миграции одной транзакцией и проверяет ready.
Краткий простой при резервном копировании и перезапуске ожидаем.
Версия обновляется только после прохождения CI. API не имеет Docker socket или shell.
При ошибке UI показывает failed: `journalctl -u mtproxy-pushok-updater --no-pager -n 80`.
База не откатывается автоматически, чтобы не потерять поступившие платежи.

## Оплата

Настройки → Платежи → «Принимать Telegram Stars» → сохранить. Проверяется наличие
токена; цена XTR задаётся отдельно. Успех оплаты подтверждается только Telegram,
не закрытием окна оплаты. Не считать живую оплату проверенной до успешного заказа.

СБП: в `.env` нужны YOOKASSA_SHOP_ID, YOOKASSA_SECRET_KEY,
PUSHOK_PUBLIC_PAYMENT_HOST=pushok.shop. PUSHOK_SBP_TEST_MODE=0 включают только
для реального магазина. PUSHOK_SBP_RECONCILIATION_ENABLED=1 включает фоновую сверку.
После изменения .env: `docker compose --profile bot up -d --force-recreate`.
Затем включите СБП в кабинете. Ключи не передавайте в чат. СБП доступна во внешнем
веб-кабинете; внутри Telegram остаётся Stars.

Бесплатный тариф: цена 0 ₽, Stars 0 или пусто. Модерация остаётся обязательной;
после одобрения оплата не требуется, внешний счёт не создаётся. Старые цены заявок
не меняются. Нулевые Stars при положительной рублёвой цене отключают Stars для тарифа.

## Проверка десяти замечаний

1. MTProxy: явный маршрут/IPv4, сохранение секрета, копия runner. Живая передача сообщений
   требует повторной проверки. Если не исправлено — проверять время, handshake и сеть.
2. Старт/тарифы/помощь/канал редактируют меню. Платёжные события и заявки сохраняются.
3. Единый экран входа: бегущий Пушок + Edge Glow, reduced-motion. Без искусственной задержки.
4. Системный шрифт, компактные формы, контрастная палитра.
5. Настройки → Система → PushokIcons: импорт реального набора, ручная привязка действий.
   Не назначаем неизвестные картинки по порядку. Mini App использует локальные SVG;
   Telegram custom emoji применяются к кнопкам бота, с fallback при явном отказе Telegram.
6. Без активных узлов можно выбрать желаемую дату «по согласованию», без фиктивной брони.
7. Компактная шапка, выход в боковом меню, поиск только для кампаний/модерации.
8. Нулевые тарифы с сохранением модерации.
9. Компактный checkbox-переключатель.
10. Настройки платежей и обновлений с действиями; техническая диагностика свёрнута.

Узел из существующей установки добавляется в реестр на паузе: проверьте сообщение
через Telegram, затем активируйте узел в разделе «Узлы». Установка службы не доказывает
доступность спонсорских показов. Тег регистрируется через @MTProxybot отдельно.
