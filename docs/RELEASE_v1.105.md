# v1.105 — Модерация и чёрный список каналов

Фото, видео и короткие подписи сами по себе не отправляют канал модератору. Когда по доступным текстам нельзя определить содержание, рекламодатель получает запрос на уточнение.

При подтверждении одной из перечисленных ниже запрещённых тематик агент отклоняет заявку и вносит канал в чёрный список по Telegram ID. Ограничение действует только на канал. Оператор может снять его в разделе «Модерация».

Агент проверяет доступные публичные тексты. Основанием для ограничения служат проверяемые сведения о содержании канала, включая эротику, тематику текущих вооружённых конфликтов, демонстрацию убийств, сбыт или пропаганду наркотиков, пропаганду терроризма и вербовку. Учитывается контекст цитаты. Фото и видео по кадрам этот выпуск не исследует.

Выбор категории «18+» в заявке приводит к отказу по этой заявке. Для общего списка нужна информация из самого канала. После снятия записи оператором новая заявка проходит обычную модерацию.

Миграция 070 создаёт журнал ограничений. В журнале сохраняются основание решения и сотрудник, снявший ограничение.
