# Иллюстрации MTProxy Pushok

Четыре отдельные иллюстрации созданы 13 ноября 2026 года для оформления GitHub в общем стиле puShok shop VPN. Это художественные изображения, не скриншоты продукта.

| Файл | Назначение |
|---|---|
| `cover.webp` | Обложка: Пушок, Telegram и серверы |
| `sponsorship.webp` | Спонсорство каналов |
| `cabinet.webp` | Кабинет и Mini App |
| `install.webp` | Установка и настройка |

Стиль: цветные карандаши и заметная штриховка, рыжий пушистый кот, бирюзово-зелёные глаза, бирюзовое худи со щитом, тёмно-синий фон и оранжевые акценты. Каждая иллюстрация — отдельный файл 1536×1024, без коллажей. WebP подготовлен для GitHub без изменения композиции; изображения встроены относительными путями и снабжены alt-текстом.

Созданы встроенной генерацией изображений; CLI/API-скрипты не использовались. Образцом оформления служили README Shop VPN и иллюстрация `docs/assets/technologies/vless.webp`; новые рисунки созданы для MTProxy.
