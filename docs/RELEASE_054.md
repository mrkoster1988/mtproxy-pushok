# v0.054 — создание заявки на одной странице

В Mini App открывается «Разместить рекламу». Выберите свой канал или укажите публичный @username, выберите тариф и при необходимости дату. Итог виден перед кнопкой «Отправить на модерацию». Отдельно сохранять канал и черновик больше не нужно.

После отправки на этой странице доступны статус, комментарий модератора и исправления. Оплата Stars появляется после одобрения при настроенном приёме. Во внешнем кабинете здесь же доступна настроенная СБП. Бесплатный тариф не создаёт счёта. Выбор даты не резервирует место, запуск требует подтверждения.

Меню Mini App: «Разместить рекламу», «Кампании», «Помощь». Остальные разделы находятся в «Ещё», администраторские — в «Управление».

## Надёжность

POST /api/v1/orders сохраняет канал, заявку на модерации, аудит и ключ отправки в одной транзакции. Повтор с тем же ключом и данными возвращает исходную заявку; другие данные дают конфликт. При потере ответа браузер сохраняет исходную отправку до получения результата. Итоговая цена и длительность сверяются с тарифом перед созданием. Чужие каналы и закрытые тарифы недоступны.

## Обновление

При установленном обработчике обновлений: «Настройки → Система → Установить обновление». В Mini App настройки доступны через «Меню → Управление». Миграция 024 добавляет таблицу ключей отправки, существующие заявки не меняются.

Если обработчик ещё не установлен, один раз выполните на VPS:

```bash
cd /opt/mtproxy-pushok && git fetch origin release/stable && git merge --ff-only FETCH_HEAD && bash scripts/install_updater.sh --enable-stars
```

Версия публикуется в release/stable после проверок. Установка на VPS и реальные платежи проверяются отдельно.
