# История изменений MTProxy Pushok

## [0.014] — 2026-11-08 (код, приёмка ожидается)

- Создан отдельный необязательный Docker Compose-профиль для Telegram-бота; он не запускается при обычном развёртывании кабинета.
- Бот работает без root, с read-only filesystem и отдельной исходящей сетью, без доступа к PostgreSQL/API.
- На старте проверяются username бота и отсутствие webhook; ошибку не исправляем автоматически и не выводим токен в логи.
- Исправлен порядок подтверждения Telegram updates после обработки; добавлены тесты конфликта webhook, неправильного токена и изоляции контейнера.
- Добавлена инструкция безопасного запуска. Не проведена реальная проверка на VPS, платежи и рекламные кампании через бота пока не реализованы.

Формат версий: X.YYY. Новые версии добавляются сверху.

## [0.013] — 2026-11-07

- Добавлен изолированный Compose smoke-test без опубликованных портов и production .env.
- Добавлены проверка повторной миграции, pg_dump/pg_restore и восстановления архива чеков.
- Проверяется сохранность тестовых данных после перезапуска API и PostgreSQL.
- Полный сценарий кампании запускается внутри Compose; добавлена инструкция приватного staging.
- Smoke-test включён в GitHub Actions отдельным заданием.

## [0.012] — 2026-11-07

- Добавлен календарь свободной ёмкости по тарифу, часовому поясу и времени начала.
- Рекламодатель может указать желаемую дату; оператор видит её при назначении.
- Доступность учитывает полную длительность тарифа, паузу узлов и пересечение интервалов; просмотр не бронирует слот.
- Добавлены проверки параметров календаря, приватности и интеграция с PostgreSQL.

## [0.011] — 2026-11-06

- Добавлены интеграционные сценарии на отдельной PostgreSQL и GitLab CI с PostgreSQL 16.
- Добавлены явные SQL-типы для строковых параметров jsonb_build_object в аудите модерации, оплаты и расписания.
- Полная установка на VPS и авторизация у реального Telegram-бота остаются отдельными проверками.

## [0.010] — 2026-11-06

- Добавлена инструкция оплаты для собственных одобренных кампаний с суммой из снимка тарифа и номером кампании.
- В кабинете добавлен просмотр реквизитов; настройка доступна в мастере установки, включая повторный запуск.
- Реквизиты не раскрываются в публичной конфигурации и для чужих заявок.
- Добавлены проверки доступа, отсутствующей настройки и сохранённой суммы.

## [0.009] — 2026-11-06

- Добавлено исправление названия и ссылки на канал из черновика или возвращённой заявки.
- Заявки со статусом changes_requested можно повторно отправить на модерацию.
- Изменение общего канала заблокировано при наличии связанных заявок вне редактируемых статусов.
- Исправление и повторная отправка согласованы блокировкой канала; добавлены проверки доступа и переходов.

## [0.008] — 2026-11-06

- Добавлен реестр прокси-узлов в кабинет владельца: название, домен/IP, TCP-порт, пауза и возобновление.
- Управление узлами ограничено ролью admin; изменения записываются в аудит.
- Пауза узла с размещениями запрещена; назначение слота и пауза синхронизированы блокировкой узла.
- Добавлены проверки API без внешних сервисов.

## [0.007] — 2026-11-06

- Добавлен setup.sh с меню компонентов, доступа к кабинету, Telegram и владельца.
- Добавлены генерация секретов, скрытый ввод токена, сохранение существующей конфигурации и режим --plan.
- Добавлены установка Docker на Ubuntu 24.04, необязательный Caddy, миграция и ожидание готовности API.
- Локальный порт API задаётся через API_BIND_PORT.

## [0.006] — 2026-11-06

- Добавлен адаптивный веб-кабинет рекламодателя и оператора на русском языке.
- Подключены Telegram-вход, каналы, тарифы, заявки, загрузка и скачивание чеков, модерация, оплата и размещение.
- Добавлены защищённые маршруты чтения каналов, узлов и метаданных чеков.
- Добавлена настройка TELEGRAM_BOT_USERNAME без раскрытия токена бота.

## [0.005] — 2026-11-06

- Добавлена загрузка подтверждения оплаты до 5 МБ в формате JPEG, PNG или PDF с проверкой сигнатуры файла.
- Файлы хранятся в закрытом Docker-томе и доступны только оператору через защищённый API-маршрут.
- Добавлен операторский список заявок с фильтрами модерации и оплаты; рекламодатель видит комментарий по проверке чека.
- Добавлена ручная проверка оплаты с обязательным комментарием при отказе.
- Добавлено назначение узла и временного интервала только для одобренной и оплаченной кампании.
- Добавлена ручная фиксация включения и завершения размещения; автоматическая смена MTProxy-тега не выполняется.
- Сценарии не запускались на VPS или тестовой базе.

## [0.004] — 2026-11-06

- Добавлен вход через Telegram Login Widget с проверкой HMAC-подписи и срока действия данных.
- Добавлены ограниченные по сроку серверные сессии, защита от повтора данных и отзыв сессии при выходе.
- Добавлены профиль пользователя, собственные каналы и кампании, отправка на модерацию.
- Добавлено операторское решение по ожидающим заявкам; одобрение переводит платёж в состояние ожидания.

## [0.003] — 2026-11-06

- Добавлен каркас API на FastAPI с проверками жизни и готовности.
- Добавлен публичный маршрут чтения активных тарифов из PostgreSQL.
- Добавлена начальная PostgreSQL-схема для пользователей, узлов MTProxy, каналов, тарифов, кампаний, подтверждений оплаты и аудита.
- Ограничены пересекающиеся интервалы размещения на одном прокси-узле на уровне PostgreSQL.
- Добавлена локальная Compose-среда с API, доступным только через loopback.

## [0.002] — 2026-11-06

- Зафиксирована спецификация MVP кабинета спонсора MTProxy: схема данных, роли, модерация, оплата, размещение и API-сценарии.
- Определён тариф по умолчанию «1 день — 300 ₽».

## [0.001] — 2026-11-06

- Создан отдельный проект MTProxy Pushok.
- Добавлен установщик MTProxy на официальном исходном коде Telegram.
- Добавлены systemd-служба, ежедневное обновление конфигурации и проверка TCP-порта.
- Добавлена инструкция регистрации прокси и ручного применения тега через @MTProxybot.
- Установка на целевом VPS ещё не выполнена.
