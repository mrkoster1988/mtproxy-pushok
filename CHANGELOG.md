# История изменений MTProxy Pushok

Формат версий: X.YYY. Новые версии добавляются сверху.

## [0.003] — 2026-11-06

- Добавлен каркас API на FastAPI с отдельными проверками жизни и готовности.
- Добавлена начальная схема PostgreSQL для пользователей, узлов MTProxy, каналов, тарифов, кампаний, подтверждений оплаты и аудита.
- Ограничены одновременные интервалы размещения на одном прокси-узле на уровне PostgreSQL.
- Добавлена локальная Compose-среда; API опубликован только на 127.0.0.1, база данных не имеет опубликованного порта.
- Аутентификация Telegram и пользовательские API-сценарии ещё не реализованы; запуск на production не проверен.

## [0.002] — 2026-11-06

- Зафиксирована спецификация MVP кабинета спонсора MTProxy: схема данных, роли, модерация, оплата, размещение и API-сценарии.
- Определены тариф по умолчанию «1 день — 300 ₽» и критерии проверки.
- Реализация кабинета и API ещё не начата.

## [0.001] — 2026-11-06

- Создан отдельный проект MTProxy Pushok.
- Добавлен установщик MTProxy на официальном исходном коде Telegram.
- Добавлены systemd-служба, ежедневное обновление конфигурации и проверка TCP-порта.
- Добавлена инструкция регистрации прокси и ручного применения тега через @MTProxybot.
- Установка на целевом VPS ещё не выполнена.
