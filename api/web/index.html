ЦЕНЫ И ТАРИФЫ

Конструктор тарифов

Создавайте платные и бесплатные тарифы. Бесплатное размещение проходит модерацию без счёта. Условия уже созданных заявок сохраняются.

Редактирование тарифа

Только для администраторов. Цена всегда 0 ₽, счёт Stars или СБП не создаётся. Можно изменить длительность и отключить тариф для новых заявок.

Способы оплаты включаются отдельно в разделе «Управление → Платежи».
